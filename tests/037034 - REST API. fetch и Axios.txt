##04::3
В чём разница между методами PUT и PATCH?
PUT заменяет ресурс целиком, PATCH обновляет только указанные поля
PUT удаляет ресурс, PATCH создаёт его
PUT работает только с JSON, PATCH только с XML
Между ними нет никакой разницы
