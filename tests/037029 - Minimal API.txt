Что такое Minimal API?

База данных для хранения HTTP-запросов
Графический редактор для создания API
Протокол передачи данных между серверами

##05::3
В чём основное преимущество Minimal API?

Обязательное использование контроллеров
Автоматическое создание базы данных
Поддержка только языка JavaScript

Для каких сценариев Minimal API подходит идеально?
Микросервисы, прототипы и простые HTTP-API
Только для больших монолитных приложений
Только для десктопных приложений
Только для работы с файлами на сервере
