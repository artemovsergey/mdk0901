##01::3
Что такое SignalR?
Библиотека для добавления функциональности реального времени в веб-приложения
База данных для хранения сообщений чата
Язык программирования для серверной разработки
Редактор кода для создания веб-страниц
##02::3
Что означает реальное время в веб-контексте?
Сервер сам отправляет данные клиенту, не дожидаясь запроса
Клиент отправляет запросы каждую секунду
Данные передаются только по электронной почте
Страница обновляется только вручную пользователем
##03::3
Что такое Hub в SignalR?
Главный компонент, который работает на сервере
Программа для подключения к базе данных
Файл настроек веб-приложения
Клиентское устройство пользователя

##06::3
Как работает Long Polling?
Клиент держит запрос открытым, пока сервер не ответит данными или не истечёт время ожидания
Клиент отправляет запрос ровно один раз при загрузке страницы
Сервер отправляет данные без запроса клиента
Клиент и сервер обмениваются файлами через диск
