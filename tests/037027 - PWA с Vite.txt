##01::3
Что такое PWA (Progressive Web App)?
Веб-приложение, которое использует современные возможности браузера и даёт опыт, близкий к нативному: работает без интернета и устанавливается на устройство
Мобильное приложение, которое устанавливается только из магазина приложений
Серверный скрипт, выполняемый на стороне бэкенда
Отдельная операционная система для запуска веб-страниц
##02::3
Какая характеристика PWA означает, что приложение открывается при отсутствии сети?
Надёжность
Скорость
Устанавливаемость
Вовлечённость
##03::3
Какой файл делает веб-приложение устанавливаемым?
Web App Manifest

##04::3
Что содержится в Web App Manifest?
Метаданные приложения: название, иконки, цвета, режим отображения
Исходный код React-компонентов
Перечень установленных зависимостей
Журнал запросов к серверу
##05::3
Что такое Service Worker?
Фоновый скрипт между приложением и сетью, который перехватывает запросы и отдаёт их из кэша, когда сети нет
Компонент React для вывода текста
Плагин для сборки стилей
Инструмент развёртывания на сервере
##06::3
Какое условие обязательно для регистрации service worker?
Защищённое HTTPS-соединение (кроме localhost)
Наличие базы данных на сервере
Установленный Docker
Версия Node.js не ниже 20

##08::3
Какая стратегия Workbox используется в vite-plugin-pwa по умолчанию?
generateSW — плагин собирает service worker, кэширующий всю статику проекта
injectManifest — ручной service worker без кэширования
stale-while-revalidate — только для изображений
CacheOnly — кэш без обновлений
##09::3
Что делает настройка registerType: 'autoUpdate'?
Новая версия приложения активируется автоматически при следующей загрузке
Обновления полностью отключаются
Установка на устройство запрещается
Кэширование статики отключается
##10::3

##11::3
Зачем добавляют иконку с purpose: 'maskable'?
Чтобы края могли обрезаться на разных платформах, поэтому важный элемент размещают в центре
Чтобы сделать иконку прозрачной
Чтобы ускорить загрузку страницы
Чтобы показывать иконку только в тёмной теме

Записью кода в index.html
##13::3
Почему службу worker нельзя проверить командой npm run dev?
Service worker регистрируется только в production-сборке, в dev-режиме его включают через devOptions.enabled
Dev-режим блокирует HTTPS
В dev-режиме недоступен localStorage
Браузер запрещает кэширование в dev-режиме

Удалить папку public
##20::3
Чем отличаются стратегии CacheFirst и NetworkFirst?
CacheFirst отдаёт данные из кэша, а NetworkFirst сначала обращается к сети и переходит к кэшу при её недоступности
CacheFirst работает только в Internet Explorer
NetworkFirst не поддерживает HTTPS
Это разные названия одной стратегии
