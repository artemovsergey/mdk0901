##01::3
Что такое React?
Библиотека JavaScript для создания пользовательских интерфейсов
Фреймворк для разработки серверных приложений
Язык программирования для браузера
Система управления базами данных
##02::3
Почему React называют библиотекой, а не фреймворком?
Он отвечает только за представление, остальное подключается отдельными библиотеками
Он не умеет создавать пользовательские интерфейсы
Он работает только с базами данных
Он не поддерживает TypeScript
##03::3
Какой подход к построению интерфейса использует React?
Декларативный: описываем, как интерфейс выглядит при текущем состоянии данных
Императивный: описываем каждый шаг обновления DOM вручную
Автоматический: интерфейс создаётся без программиста
Статический: интерфейс создаётся один раз и не меняется
##04::3
Что такое компонент в React?
Функция, которая возвращает JSX-разметку
Отдельный файл со стилями приложения
Модуль для работы с сервером
Набор HTML-страниц
##05::3
Что такое JSX?
Расширение синтаксиса JavaScript, позволяющее писать разметку прямо в коде
Язык разметки для создания стилей страниц
Инструмент для сборки проекта
Библиотека для работы с базами данных
##06::3
Какой атрибут JSX используется вместо class?
className
classStyle
cssClass
classNode
##07::3
Как вставить выражение JavaScript в JSX?
Заключить его в фигурные скобки
Записать его в двойных кавычках
Обернуть его в квадратные скобки
Передать его через атрибут style
##08::3
Что такое props?
Входные данные компонента, передаваемые как атрибуты JSX
Внутренние переменные, создаваемые внутри компонента
Стили корневого компонента
Список зависимостей проекта
##09::3
Что такое state в React?
Внутренние данные компонента, при изменении которых React перерисовывает интерфейс
Статический файл настройки приложения
Служебный атрибут списка
Разметка, возвращаемая компонентом
##10::3
Что такое хуки в React?
Функции useState, useEffect и другие, дающие компоненту возможности React
Инструменты для сборки production-версии
Набор CSS-правил для оформления
Компоненты для работы с формами

##15::3
Почему в проекте используется TypeScript?

##17::3
Что означает горячая замена модулей (HMR)?
Изменения сразу видны в браузере без полной перезагрузки
Весь проект пересобирается с нуля после каждой правки
Страница перезагружается при каждом изменении кода
Сервер перезапускается вручную
