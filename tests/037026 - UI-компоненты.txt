##01::3
Что такое Tailwind CSS?
CSS-фреймворк, построенный на утилитарных классах
Язык программирования для серверной части
База данных для хранения стилей
Графический редактор интерфейсов
##02::3
Где описывается оформление компонентов в Tailwind?
Классами прямо в JSX: flex, gap-4, rounded-lg
В отдельном файле стилей под каждый компонент
В базе данных на сервере
В конфигурации операционной системы
##03::3
Какое из преимуществ Tailwind перечислено в лекции?
Нет «мёртвого» CSS и придумывания имён классов
Автоматическая генерация изображений для сайта
Отдельные цвета для каждого пикселя экрана
Обязательное использование библиотеки jQuery
##04::3

Через файл tailwind.config.js
Через CDN-ссылку в HTML

Типы TypeScript в проекте
##07::3
Что такое shadcn/ui?
Набор исходного кода компонентов, копируемый в проект командой
Готовая npm-библиотека с закрытым кодом
Расширение для браузера Chrome
Серверный фреймворк для создания API
##08::3
На чём построены компоненты shadcn/ui?
На Radix UI, Tailwind CSS и class-variance-authority
На jQuery и Bootstrap
На Vue и Element Plus
На Angular Material
##09::3
Что обеспечивает Radix UI в компонентах shadcn/ui?
Доступность из коробки: клавиатура, ARIA, фокус
Автоматическую генерацию кода компонентов
Резервное копирование данных пользователя
Встроенную аналитику посещений
##10::3

В public/assets
В src/lib/utils

Только после покупки платной лицензии
