Хук для обработки событий мыши
Компонент для отображения списка
Middleware для логирования запросов

Reducer обязан использовать console.log
Reducer должен менять состояние напрямую

Обычной функцией без параметров

Простой глобальный стор на встроенных средствах React
Серверное кэширование данных
Автоматическую синхронизацию с базой данных
Оптимизацию ререндеров всех компонентов
##10::3
Какое ограничение есть у подхода Context + useReducer?
При изменении значения провайдера перерисовываются все потребители контекста
Context нельзя использовать в React приложениях
Reducer не работает с TypeScript
Context стирает состояние при перезагрузке страницы

Небольшая библиотека для глобального состояния
Язык запросов к базе данных

Система сборки фронтенд-проектов

Обёрткой компонента в Provider

Компонент для вывода ошибок
