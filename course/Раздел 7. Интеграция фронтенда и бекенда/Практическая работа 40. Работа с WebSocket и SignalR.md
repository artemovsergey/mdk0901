# Практическая работа 40. Работа с WebSocket и SignalR

### **Тема:** Реальное время в React-приложении: WebSocket и SignalR

### **Цель:**
Освоить работу с двунаправленными соединениями в браузере: понять, как устроен протокол WebSocket, научиться подключаться к SignalR-хабу из React-приложения через библиотеку `@microsoft/signalr`, обрабатывать события сервера, отправлять сообщения и корректно управлять жизненным циклом соединения с помощью пользовательского хука.

### **Теоретическая часть:**

**WebSocket** — это протокол связи поверх одного TCP-соединения, который обеспечивает **полнодуплексный** (двунаправленный) обмен данными. И клиент, и сервер могут отправлять сообщения в любой момент, не дожидаясь запроса противоположной стороны.

**Как устанавливается соединение (рукопожатие):**
1. Клиент отправляет обычный HTTP-запрос с заголовками `Upgrade: websocket`, `Connection: Upgrade` и ключом `Sec-WebSocket-Key`.
2. Сервер подтверждает переход и отвечает статусом `101 Switching Protocols`.
3. После этого HTTP-протокол больше не используется — стороны обмениваются WebSocket-кадрами в обе стороны до закрытия соединения.

**Чем WebSocket отличается от обычных HTTP-запросов:**

| HTTP-запрос | WebSocket |
|-------------|-----------|
| Модель «запрос → ответ» | Постоянный двунаправленный канал |
| Инициатор почти всегда клиент | Инициатором может быть и сервер |
| Заголовки передаются при каждом запросе | Накладные расходы только на этапе рукопожатия |
| Сервер не может «сам» сообщить об изменении | Сервер мгновенно push-ит события клиенту |

Когда нужен WebSocket: чаты, уведомления, биржевые котировки, совместное редактирование, онлайн-игры, мониторинг. Когда не нужен: обычные CRUD-запросы, данные, которые можно получить по REST с кэшированием (TanStack Query + Axios).

**SignalR** — библиотека ASP.NET Core, которая упрощает работу с real-time. Она сама выбирает доступный транспорт (WebSocket, Server-Sent Events, Long Polling) и берёт на себя переподключение, групповую рассылку и сериализацию:

```
React-клиент (@microsoft/signalr) ⇄ WebSocket ⇄ ASP.NET Core (SignalR Hub)
```

**Основные понятия SignalR:**
- **Hub (хаб)** — класс на сервере, методы которого можно вызывать с клиента, и наоборот.
- **Clients** — адресация получателей: `Clients.All`, `Clients.Caller`, `Clients.Others`, группы.
- **Группы** — логические объединения соединений (например, комнаты чата).
- **Методы/события** — именованные вызовы между клиентом и хабом.

```ts
  })

  .configureLogging(LogLevel.Information)

```

**Основной API объекта `HubConnection`:**

| Метод / свойство | Назначение |
|------------------|-----------|
| `start()` | Устанавливает соединение (возвращает `Promise`) |
| `stop()` | Закрывает соединение (возвращает `Promise`) |
| `on(method, handler)` | Подписка на событие, которое присылает сервер |
| `off(method, handler)` | Удаление конкретной подписки |
| `invoke(method, ...args)` | Вызов метода хаба с ожиданием результата и ошибок |
| `send(method, ...args)` | Вызов метода хаба без ожидания результата («выстрелил и забыл») |
| `connection.state` | Текущее состояние (`HubConnectionState`) |
| `onreconnecting(cb)` | Начался процесс переподключения |
| `onreconnected(cb)` | Соединение восстановлено |
| `onclose(cb)` | Соединение окончательно закрыто |

**Разница между `invoke` и `send`:**
- `invoke` возвращает `Promise`, ждёт ответа сервера и позволяет поймать ошибку — используйте для команд, где важен результат (`SendMessage`, `GetOnlineUsers`).
- `send` не ждёт ответа и работает быстрее — годится для «шумных» событий (движение курсора, координаты рисования).

**Пользовательский хук `useSignalR`.** В React соединение создаётся внутри `useEffect`, а в возвращаемой функции очистки обязательно вызывается `connection.stop()`. Это критично, потому что в режиме разработки React 19 (StrictMode) монтирует компоненты дважды и без очистки останутся «висячие» соединения. Колбэки и токен хранят в `useRef`, чтобы они не пересоздавали соединение на каждый рендер.

**Типизация.** В проекте включён `verbatimModuleSyntax`, поэтому типы импортируются отдельно: `import type { HubConnection } from '@microsoft/signalr';`, а значения (классы, перечисления) — обычным импортом: `import { HubConnectionBuilder, HubConnectionState, LogLevel } from '@microsoft/signalr';`.

**5. src/hooks/useSignalR.ts — хук управления соединением:**

```tsx
import { useCallback, useEffect, useRef, useState } from 'react';
import {
  HubConnectionBuilder,
  HubConnectionState,
  LogLevel,
} from '@microsoft/signalr';
import type { HubConnection } from '@microsoft/signalr';

export type ConnectionStatus =
  | 'connecting'
  | 'connected'
  | 'reconnecting'
  | 'disconnected';

// Обработчики событий сервера: ключ — имя метода хаба.
type HubEventHandlers = Record<string, (...args: never[]) => void>;

interface UseSignalROptions {
  url: string;
  handlers: HubEventHandlers;
  getToken?: () => string | null;
  onReconnected?: (connection: HubConnection) => void;
  enabled?: boolean;
}

export function useSignalR({
  url,
  handlers,
  getToken,
  onReconnected,
  enabled = true,
}: UseSignalROptions) {
  const [status, setStatus] = useState<ConnectionStatus>('disconnected');
  const [reconnectKey, setReconnectKey] = useState(0);
  const connectionRef = useRef<HubConnection | null>(null);

  // Актуальные колбэки держим в ref, чтобы не пересоздавать соединение на каждый рендер.
  const handlersRef = useRef(handlers);
  handlersRef.current = handlers;
  const getTokenRef = useRef(getToken);
  getTokenRef.current = getToken;
  const onReconnectedRef = useRef(onReconnected);
  onReconnectedRef.current = onReconnected;

  useEffect(() => {
    if (!enabled) return;

    const connection = new HubConnectionBuilder()
      .withUrl(url, {
        accessTokenFactory: () => getTokenRef.current?.() ?? '',
      })
      .withAutomaticReconnect([0, 2000, 5000, 10000, 30000])
      .configureLogging(LogLevel.Information)
      .build();

    connectionRef.current = connection;

    // 1. Подписки на события сервера. Запоминаем пары «метод — обёртка» для off().
    const boundHandlers = Object.keys(handlersRef.current).map((method) => {
      const handler = (...args: unknown[]) => {
        const current = handlersRef.current[method] as
          | ((...args: unknown[]) => void)
          | undefined;
        current?.(...args);
      };
      connection.on(method, handler);
      return { method, handler };
    });

    // 2. События жизненного цикла соединения.
    connection.onreconnecting((error) => {
      console.warn('SignalR: переподключение...', error);
      setStatus('reconnecting');
    });

    connection.onreconnected(() => {
      setStatus('connected');
      onReconnectedRef.current?.(connection);
    });

    connection.onclose((error) => {
      console.warn('SignalR: соединение закрыто', error);
      setStatus('disconnected');
    });

    // 3. Запуск соединения.
    let cancelled = false;
    setStatus('connecting');
    connection
      .start()
      .then(() => {
        if (!cancelled) setStatus('connected');
      })
      .catch((error: unknown) => {
        if (!cancelled) {
          console.error('SignalR: не удалось подключиться', error);
          setStatus('disconnected');
        }
      });

    // 4. Очистка: снимаем подписки и останавливаем соединение.
    return () => {
      cancelled = true;
      boundHandlers.forEach(({ method, handler }) => connection.off(method, handler));
      void connection.stop();
      connectionRef.current = null;
    };
  }, [url, enabled, reconnectKey]);

  const invoke = useCallback(async (method: string, ...args: unknown[]) => {
    const connection = connectionRef.current;
    if (!connection || connection.state !== HubConnectionState.Connected) {
      console.warn(`SignalR: метод ${method} пропущен — нет соединения`);
      return undefined;
    }
    return connection.invoke(method, ...args);
  }, []);

  const send = useCallback(async (method: string, ...args: unknown[]) => {
    const connection = connectionRef.current;
    if (!connection || connection.state !== HubConnectionState.Connected) {
      console.warn(`SignalR: метод ${method} пропущен — нет соединения`);
      return;
    }
    await connection.send(method, ...args);
  }, []);

  const reconnect = useCallback(() => setReconnectKey((key) => key + 1), []);

  return { status, invoke, send, reconnect };
}
```

**9. src/components/MessageForm.tsx — отправка сообщения:**

```tsx
import { useState } from 'react';
import type { FormEvent } from 'react';

interface MessageFormProps {
  disabled: boolean;
  onSend: (text: string) => Promise<void>;
}

export function MessageForm({ disabled, onSend }: MessageFormProps) {
  const [text, setText] = useState('');
  const [isSending, setIsSending] = useState(false);

  const handleSubmit = async (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const trimmed = text.trim();
    if (!trimmed || isSending) return;

    setIsSending(true);
    try {
      await onSend(trimmed);
      setText('');
    } finally {
      setIsSending(false);
    }
  };

  return (
    <form className="message-form" onSubmit={handleSubmit}>
      <label className="sr-only" htmlFor="message-text">
        Текст сообщения
      </label>
      <input
        id="message-text"
        className="message-input"
        type="text"
        value={text}
        onChange={(event) => setText(event.target.value)}
        placeholder="Введите сообщение..."
        autoComplete="off"
        disabled={disabled}
      />
      <button
        className="send-button"
        type="submit"
        disabled={disabled || isSending || text.trim().length === 0}
      >
        {isSending ? 'Отправка...' : 'Отправить'}
      </button>
    </form>
  );
}
```

**11. src/pages/ChatPage.tsx — подключение хука к интерфейсу:**

```tsx
import { useCallback, useMemo, useState } from 'react';
import type { ChatMessage, OnlineUser } from '../types/chat';
import { HUB_URL } from '../lib/hub';
import { useSignalR } from '../hooks/useSignalR';
import { ConnectionBadge } from '../components/ConnectionBadge';
import { MessageList } from '../components/MessageList';
import { MessageForm } from '../components/MessageForm';
import { OnlineUsersList } from '../components/OnlineUsersList';

interface ChatPageProps {
  nickname: string;
}

export function ChatPage({ nickname }: ChatPageProps) {
  const [messages, setMessages] = useState<ChatMessage[]>([]);
  const [onlineUsers, setOnlineUsers] = useState<OnlineUser[]>([]);

  // Набор обработчиков событий сервера. Ключи должны совпадать с именами методов хаба.
  const handlers = useMemo(
    () => ({
      ReceiveMessage: (message: ChatMessage) => {
        setMessages((prev) => [...prev, message]);
      },
      OnlineUsersUpdated: (users: OnlineUser[]) => {
        setOnlineUsers(users);
      },
    }),
    [],
  );

  const { status, invoke, reconnect } = useSignalR({
    url: HUB_URL,
    handlers,
    getToken: () => localStorage.getItem('access_token'),
    // После переподключения заново запрашиваем список онлайн-пользователей.
    onReconnected: (connection) => {
      void connection.invoke('GetOnlineUsers');
    },
  });

  const handleSend = useCallback(
    async (text: string) => {
      await invoke('SendMessage', { user: nickname, text });
    },
    [invoke, nickname],
  );

  return (
    <div className="chat-layout">
      <header className="chat-header">
        <h1>Чат реального времени</h1>
        <ConnectionBadge status={status} onReconnect={reconnect} />
      </header>

      <div className="chat-body">
        <MessageList messages={messages} currentUser={nickname} />
        <OnlineUsersList users={onlineUsers} />
      </div>

      <MessageForm disabled={status !== 'connected'} onSend={handleSend} />
    </div>
  );
}
```

**Серверная часть (справочно).** Клиент ожидает от хаба четыре события. Минимальный хаб на ASP.NET Core может выглядеть так:

```csharp
public class ChatHub : Hub
{
    private static readonly ConcurrentDictionary<string, string> OnlineUsers = new();

    public override async Task OnConnectedAsync()
    {
        var nickname = Context.User?.Identity?.Name
            ?? $"Гость-{Context.ConnectionId[..4]}";
        OnlineUsers[Context.ConnectionId] = nickname;

        await Clients.All.SendAsync("OnlineUsersUpdated", ToList());
        await base.OnConnectedAsync();
    }

    public override async Task OnDisconnectedAsync(Exception? exception)
    {
        OnlineUsers.TryRemove(Context.ConnectionId, out _);
        await Clients.All.SendAsync("OnlineUsersUpdated", ToList());
        await base.OnDisconnectedAsync(exception);
    }

    public Task GetOnlineUsers() => Clients.Caller.SendAsync("OnlineUsersUpdated", ToList());

    public Task SendMessage(string user, string text)
    {
        var message = new
        {
            Id = Guid.NewGuid().ToString(),
            User = user,
            Text = text,
            SentAt = DateTime.UtcNow.ToString("o"),
        };
        return Clients.All.SendAsync("ReceiveMessage", message);
    }

    private static object ToList() => OnlineUsers
        .Select(u => new { ConnectionId = u.Key, Nickname = u.Value })
        .ToList();
}
```

````markdown
#### src/hooks/useSignalR.ts
```tsx
import { useCallback, useEffect, useRef, useState } from 'react';
import { HubConnectionBuilder, HubConnectionState, LogLevel } from '@microsoft/signalr';
import type { HubConnection } from '@microsoft/signalr';

export type ConnectionStatus =
  | 'connecting'
  | 'connected'
  | 'reconnecting'
  | 'disconnected';

type HubEventHandlers = Record<string, (...args: never[]) => void>;

interface UseSignalROptions {
  url: string;
  handlers: HubEventHandlers;
  getToken?: () => string | null;
}

export function useSignalR({ url, handlers, getToken }: UseSignalROptions) {
  const [status, setStatus] = useState<ConnectionStatus>('disconnected');
  const connectionRef = useRef<HubConnection | null>(null);
  const handlersRef = useRef(handlers);
  handlersRef.current = handlers;

  useEffect(() => {
    const connection = new HubConnectionBuilder()
      .withUrl(url, { accessTokenFactory: () => getToken?.() ?? '' })
      .withAutomaticReconnect([0, 2000, 5000, 10000, 30000])
      .configureLogging(LogLevel.Information)
      .build();

    connectionRef.current = connection;

    const boundHandlers = Object.keys(handlersRef.current).map((method) => {
      const handler = (...args: unknown[]) => {
        const current = handlersRef.current[method] as
          | ((...args: unknown[]) => void)
          | undefined;
        current?.(...args);
      };
      connection.on(method, handler);
      return { method, handler };
    });

    connection.onreconnecting(() => setStatus('reconnecting'));
    connection.onreconnected(() => setStatus('connected'));
    connection.onclose(() => setStatus('disconnected'));

    setStatus('connecting');
    connection
      .start()
      .then(() => setStatus('connected'))
      .catch((error: unknown) => {
        console.error('SignalR: не удалось подключиться', error);
        setStatus('disconnected');
      });

    return () => {
      boundHandlers.forEach(({ method, handler }) => connection.off(method, handler));
      void connection.stop();
      connectionRef.current = null;
    };
  }, [url, getToken]);

  const invoke = useCallback(async (method: string, ...args: unknown[]) => {
    const connection = connectionRef.current;
    if (!connection || connection.state !== HubConnectionState.Connected) return;
    return connection.invoke(method, ...args);
  }, []);

  return { status, invoke };
}
```

#### src/components/NotificationFeed.tsx
```tsx
import { useMemo, useState } from 'react';
import { HUB_URL } from '../lib/hub';
import { useSignalR } from '../hooks/useSignalR';

interface Notification {
  id: string;
  title: string;
  createdAt: string;
}

export function NotificationFeed() {
  const [items, setItems] = useState<Notification[]>([]);
  const [unread, setUnread] = useState(0);

  const handlers = useMemo(
    () => ({
      ReceiveNotification: (notification: Notification) => {
        setItems((prev) => [notification, ...prev]);
        setUnread((count) => count + 1);
      },
    }),
    [],
  );

  const { status } = useSignalR({ url: HUB_URL, handlers });

  return (
    <section className="notifications">
      <header>
        <h1>Уведомления</h1>
        <span>Непрочитанных: {unread}</span>
        <button type="button" onClick={() => setUnread(0)}>
          Прочитать все
        </button>
        <span>{status === 'connected' ? 'На связи' : 'Нет связи'}</span>
      </header>

      {items.length === 0 ? (
        <p>Уведомлений пока нет</p>
      ) : (
        <ul>
          {items.map((item) => (
            <li key={item.id}>
              {item.title}
              <time dateTime={item.createdAt}>
                {new Date(item.createdAt).toLocaleTimeString('ru-RU')}
              </time>
            </li>
          ))}
        </ul>
      )}
    </section>
  );
}
````
