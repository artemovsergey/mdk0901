# Практическая работа 35. Применение TanStack Query

### **Тема:** Управление серверным состоянием в React с помощью TanStack Query

### **Цель:**
Освоить практические навыки работы с серверным состоянием в React-приложении: настройку `QueryClientProvider`, загрузку данных через `useQuery`, обработку состояний загрузки и ошибки, изменение данных через `useMutation` с инвалидацией кэша, использование пагинации и панели Devtools.

### **Теоретическая часть:**

**Серверное состояние** — это данные, которые хранятся на сервере и лишь отображаются в интерфейсе: список товаров, каталог записей, профиль пользователя. В отличие от клиентского состояния (открытое окно, выбранная тема), серверные данные могут устареть и требуют кэширования и синхронизации.

**TanStack Query** — библиотека для работы с серверным состоянием в React. Она берёт на себя загрузку, кэширование, повторные запросы и обновление данных после изменений.

**Ключевые понятия:**

- **`QueryClient`** — хранит кэш всех запросов, создаётся один раз на приложение.
- **`QueryClientProvider`** — передаёт клиент вниз по дереву компонентов.
- **`queryKey`** — массив-ключ, по которому библиотека различает записи кэша, например `['posts']` или `['posts', page]`.
- **`queryFn`** — функция, которая выполняет запрос и возвращает промис.
- **`staleTime`** — сколько времени данные считаются свежими (повторный запрос не выполняется).
- **`gcTime`** — сколько времени несвежие данные хранятся в памяти.
- **`useQuery`** — хук для чтения данных. Возвращает `data` и статусы `isPending`, `isError`, `isSuccess`, `isFetching`.
- **`useMutation`** — хук для изменения данных (`POST`, `PUT`, `DELETE`).
- **`invalidateQueries`** — помечает данные устаревшими, после чего активные запросы автоматически перезагружаются.
- **Devtools** — панель разработчика со списком запросов и состоянием кэша.

**Минимальный пример загрузки данных:**

```tsx
import { useQuery } from '@tanstack/react-query';

function Posts() {
  const { data, isPending, isError, error } = useQuery({
    queryKey: ['posts'],
    queryFn: fetchPosts,
    staleTime: 30_000,
  });

  if (isPending) return <p>Загрузка…</p>;
  if (isError) return <p role="alert">{error.message}</p>;

  return <ul>{data.map((post) => <li key={post.id}>{post.title}</li>)}</ul>;
}
```

**Правила работы с серверными данными:**

- Один `QueryClient` и один `QueryClientProvider` на всё приложение.
- Каждому набору данных — свой устойчивый `queryKey`.
- Сетевые запросы выносятся в модуль `src/api/`, компоненты не знают деталей сети.
- После мутаций кэш инвалидируется через `invalidateQueries`.
- Все состояния (`isPending`, `isError`, пустой список) должны быть отображены пользователю.

```tsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { ReactQueryDevtools } from '@tanstack/react-query-devtools';
import './index.css';
import App from './App.tsx';

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 30_000,
      gcTime: 5 * 60_000,
      refetchOnWindowFocus: false,
    },
  },
});

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <QueryClientProvider client={queryClient}>
      <App />
      <ReactQueryDevtools initialIsOpen={false} />
    </QueryClientProvider>
  </StrictMode>,
);
```

**3. Модуль API — `src/api/posts.ts`:**

```ts
import axios from 'axios';

export interface Post {
  id: number;
  userId: number;
  title: string;
  body: string;
}

export type NewPost = Omit<Post, 'id'>;

const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL ?? 'https://jsonplaceholder.typicode.com',
  headers: {
    'Content-Type': 'application/json',
    Accept: 'application/json',
  },
  timeout: 8000,
});

export async function fetchPosts(): Promise<Post[]> {
  const { data } = await api.get<Post[]>('/posts', {
    params: { _limit: 12 },
  });
  return data;
}

export async function createPost(payload: NewPost): Promise<Post> {
  const { data } = await api.post<Post>('/posts', payload);
  return data;
}

export async function deletePost(id: number): Promise<void> {
  await api.delete(`/posts/${id}`);
}
```

**4. Форма добавления — `src/components/AddPostForm.tsx`:**

```tsx
import { useState } from 'react';
import type { FormEvent } from 'react';
import { useMutation, useQueryClient } from '@tanstack/react-query';
import { createPost } from '../api/posts';
import type { NewPost } from '../api/posts';

export function AddPostForm() {
  const [title, setTitle] = useState('');
  const [body, setBody] = useState('');
  const queryClient = useQueryClient();

  const { mutate, isPending, isError, error, reset } = useMutation({
    mutationFn: (payload: NewPost) => createPost(payload),
    onSuccess: () => {
      setTitle('');
      setBody('');
      // Помечаем кэш устаревшим — список обновится автоматически.
      void queryClient.invalidateQueries({ queryKey: ['posts'] });
    },
  });

  function handleSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    mutate({ userId: 1, title, body });
  }

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <label htmlFor="title">Заголовок</label>
        <input
          id="title"
          value={title}
          onChange={(event) => setTitle(event.target.value)}
          required
        />
      </div>

      <div>
        <label htmlFor="body">Текст</label>
        <textarea
          id="body"
          value={body}
          onChange={(event) => setBody(event.target.value)}
          required
        />
      </div>

      <button type="submit" disabled={isPending}>
        {isPending ? 'Сохранение…' : 'Добавить запись'}
      </button>

      {isError && (
        <p role="alert">
          {error.message}{' '}
          <button type="button" onClick={() => reset()}>
            Сбросить
          </button>
        </p>
      )}
    </form>
  );
}
```

**5. Каталог — `src/components/PostsCatalog.tsx`:**

```tsx
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import { deletePost, fetchPosts } from '../api/posts';
import type { Post } from '../api/posts';

export function PostsCatalog() {
  const queryClient = useQueryClient();

  const { data, status, error, isFetching, refetch } = useQuery<Post[], Error>({
    queryKey: ['posts'],
    queryFn: fetchPosts,
    staleTime: 30_000,
  });

  const removeMutation = useMutation({
    mutationFn: (id: number) => deletePost(id),
    onSuccess: () => {
      void queryClient.invalidateQueries({ queryKey: ['posts'] });
    },
  });

  if (status === 'pending') {
    return <p>Загрузка каталога…</p>;
  }

  if (status === 'error') {
    return (
      <div role="alert">
        <p>Не удалось загрузить каталог: {error.message}</p>
        <button type="button" onClick={() => void refetch()}>
          Повторить
        </button>
      </div>
    );
  }

  return (
    <section>
      <header>
        <h2>Каталог записей</h2>
        <button type="button" onClick={() => void refetch()} disabled={isFetching}>
          {isFetching ? 'Обновление…' : 'Обновить'}
        </button>
      </header>

      {data.length === 0 ? (
        <p>Список пуст. Добавьте первую запись.</p>
      ) : (
        <ul>
          {data.map((post) => (
            <li key={post.id}>
              <article>
                <h3>{post.title}</h3>
                <p>{post.body}</p>
              </article>
              <button
                type="button"
                onClick={() => removeMutation.mutate(post.id)}
                disabled={removeMutation.isPending}
              >
                Удалить
              </button>
            </li>
          ))}
        </ul>
      )}
    </section>
  );
}
```

### Задание:
Реализовать поиск записей с задержкой 300 мс после ввода (debounce). Запрос выполняется только при изменении значения и только если строка не пустая.

### Реализация:

#### src/api/posts.ts
```ts
import axios from 'axios';

export interface Post {
  id: number;
  userId: number;
  title: string;
  body: string;
}

const api = axios.create({
  baseURL: 'https://jsonplaceholder.typicode.com',
  headers: { 'Content-Type': 'application/json' },
  timeout: 8000,
});

export async function searchPosts(term: string): Promise<Post[]> {
  const { data } = await api.get<Post[]>('/posts', {
    params: { title_like: term, _limit: 10 },
  });
  return data;
}
```

#### src/components/SearchPosts.tsx
```tsx
import { useEffect, useState } from 'react';
import { useQuery } from '@tanstack/react-query';
import { searchPosts } from '../api/posts';

export function SearchPosts() {
  const [term, setTerm] = useState('');
  const [debouncedTerm, setDebouncedTerm] = useState('');

  // Задержка 300 мс после последнего ввода.
  useEffect(() => {
    const timer = setTimeout(() => setDebouncedTerm(term.trim()), 300);
    return () => clearTimeout(timer);
  }, [term]);

  const { data, isPending, isError, error, isFetching } = useQuery({
    queryKey: ['search', debouncedTerm],
    queryFn: () => searchPosts(debouncedTerm),
    // Запрос выполняется только при непустой строке.
    enabled: debouncedTerm.length > 0,
  });

  return (
    <section>
      <label htmlFor="search">Поиск записей</label>
      <input
        id="search"
        value={term}
        onChange={(event) => setTerm(event.target.value)}
        placeholder="Введите заголовок…"
      />

      {isFetching && <p>Поиск…</p>}

      {isError && <p role="alert">Ошибка: {error.message}</p>}

      {isPending && debouncedTerm.length > 0 && <p>Загрузка результатов…</p>}

      {data && data.length === 0 && (
        <p>Ничего не найдено по запросу «{debouncedTerm}».</p>
      )}

      {data && data.length > 0 && (
        <ul>
          {data.map((post) => (
            <li key={post.id}>{post.title}</li>
          ))}
        </ul>
      )}
    </section>
  );
}
```

3. Создать React-проект в папке репозитория:
   ```bash
   npm create vite@latest . -- --template react-ts
   npm install
   npm install @tanstack/react-query axios
   npm install -D @tanstack/react-query-devtools
   ```
4. Реализовать функциональность согласно варианту задания
5. Сделать коммиты с понятными сообщениями
6. Добавить скриншоты работы (состояния загрузки, ошибки, успеха) в папку `assets/images`
7. Оформить README.md с описанием задания, хода работы и скриншотами
8. Запушить изменения в Gogs
9. Предоставить ссылку на репозиторий преподавателю
