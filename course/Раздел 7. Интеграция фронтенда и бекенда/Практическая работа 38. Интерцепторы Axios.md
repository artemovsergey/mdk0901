# Практическая работа 38. Интерцепторы Axios

### **Тема:** Интерцепторы Axios — централизованная обработка запросов и ответов

### **Цель:**
Научиться создавать и применять интерцепторы Axios для централизованной обработки HTTP-запросов и ответов в React-приложении. Освоить добавление заголовка авторизации, обновление токена с очередью запросов, нормализацию ошибок, логирование и отключение интерцепторов.

### **Теоретическая часть:**

**Что такое интерцептор.** Интерцептор (interceptor) — это функция-посредник, через которую проходит каждый запрос перед отправкой и каждый ответ до того, как его получит код приложения. Интерцепторы позволяют один раз описать общую логику для всех запросов вместо того, чтобы повторять её в каждом компоненте.

**Зачем нужны интерцепторы:**

*   добавить заголовок `Authorization` ко всем защищённым запросам;
*   залогировать запрос, ответ и время выполнения;
*   привести любую ошибку к единому формату;
*   обновить токен при ответе 401 и повторить исходный запрос;
*   показать общий индикатор загрузки;
*   закэшировать GET-запросы.

**Инстанс Axios.** Интерцепторы навешивают на конкретный экземпляр Axios, поэтому сначала создают его в отдельном модуле:

```ts
// src/api/http.ts
import axios from 'axios';

export const http = axios.create({
  baseURL: import.meta.env.VITE_API_URL,
  headers: { 'Content-Type': 'application/json' },
  timeout: 10_000,
});
```

**Интерцептор запроса.** Регистрируется через `http.interceptors.request.use(onFulfilled, onRejected)`. Функция получает конфигурацию запроса и должна вернуть её (возможно, изменённую):

```ts
const id = http.interceptors.request.use((config) => {
  const token = localStorage.getItem('access_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
```

**Интерцептор ответа.** Регистрируется через `http.interceptors.response.use(onFulfilled, onRejected)`. Первая функция обрабатывает успешный ответ, вторая — ошибку:

```ts
http.interceptors.response.use(
  (response) => response,
  (error) => Promise.reject(normalizeError(error)),
);
```

**Защита от рекурсии.** Если интерцептор при ответе 401 сам отправляет запрос на обновление токена через тот же экземпляр `http`, сработает тот же интерцептор, и при повторной ошибке возникнет бесконечный цикл. Решают это двумя приёмами:

1.  **флаг на конфигурации** (`_retry`) — запрос повторяется только один раз;
2.  **отдельный «чистый» экземпляр Axios** (`refreshClient`) без интерцепторов — используется только для обновления токена.

**Очередь запросов при обновлении токена.** Пока идёт обновление токена, другие запросы могут тоже получить 401. Чтобы не запускать обновление несколько раз, используют очередь: первый запрос обновляет токен, остальные ждут результата в массиве функций, а после обновления повторяются с новым токеном.

**Отключение интерцептора.** Метод `use` возвращает идентификатор, который можно передать в `eject`:

```ts
const id = http.interceptors.request.use(/** ... */);

// Позже:
http.interceptors.request.eject(id);
```

**1. Класс ошибки и нормализация — `src/api/errors.ts`:**

```ts
import axios from 'axios';

export type ApiErrorKind =
  | 'network'
  | 'timeout'
  | 'unauthorized'
  | 'forbidden'
  | 'notFound'
  | 'validation'
  | 'server'
  | 'unknown';

interface ServerFieldError {
  field: string;
  message: string;
}

interface ServerErrorBody {
  message?: string;
  errors?: ServerFieldError[];
}

// Единый класс ошибки: интерцептор всегда отклоняет запрос таким объектом.
export class ApiError extends Error {
  kind: ApiErrorKind;
  status?: number;
  fieldErrors: Record<string, string>;

  constructor(input: {
    kind: ApiErrorKind;
    message: string;
    status?: number;
    fieldErrors?: Record<string, string>;
  }) {
    super(input.message);
    this.name = 'ApiError';
    this.kind = input.kind;
    this.status = input.status;
    this.fieldErrors = input.fieldErrors ?? {};
  }
}

// Приводит любую ошибку к классу ApiError с понятным сообщением.
export function normalizeError(error: unknown): ApiError {
  if (!axios.isAxiosError(error)) {
    return new ApiError({
      kind: 'unknown',
      message: error instanceof Error ? error.message : 'Неизвестная ошибка',
    });
  }

  // Ответа нет: запрос не дошёл до сервера.
  if (!error.response) {
    if (error.code === 'ECONNABORTED') {
      return new ApiError({ kind: 'timeout', message: 'Сервер не ответил вовремя' });
    }
    return new ApiError({ kind: 'network', message: 'Нет соединения с сервером' });
  }

  const status = error.response.status;
  const body = error.response.data as ServerErrorBody | undefined;

  switch (status) {
    case 400:
    case 422:
      return new ApiError({
        kind: 'validation',
        status,
        message: body?.message ?? 'Проверьте заполнение полей',
        fieldErrors: (body?.errors ?? []).reduce<Record<string, string>>((acc, item) => {
          acc[item.field] = item.message;
          return acc;
        }, {}),
      });
    case 401:
      return new ApiError({ kind: 'unauthorized', status, message: 'Требуется авторизация' });
    case 403:
      return new ApiError({ kind: 'forbidden', status, message: 'Доступ запрещён' });
    case 404:
      return new ApiError({ kind: 'notFound', status, message: 'Ресурс не найден' });
    default:
      return status >= 500
        ? new ApiError({ kind: 'server', status, message: 'Ошибка на сервере' })
        : new ApiError({
            kind: 'unknown',
            status,
            message: body?.message ?? 'Неизвестная ошибка',
          });
  }
}

// Короткое сообщение для показа в интерфейсе.
export function getErrorMessage(error: unknown): string {
  return normalizeError(error).message;
}
```

**2. Хранилище токена на Zustand — `src/store/authStore.ts`:**

```ts
import { create } from 'zustand';

interface AuthState {
  accessToken: string | null;
  setAccessToken: (token: string | null) => void;
  clear: () => void;
}

const ACCESS_KEY = 'access_token';
const REFRESH_KEY = 'refresh_token';

export const useAuthStore = create<AuthState>((set) => ({
  accessToken: localStorage.getItem(ACCESS_KEY),
  setAccessToken: (token) => {
    if (token) {
      localStorage.setItem(ACCESS_KEY, token);
    } else {
      localStorage.removeItem(ACCESS_KEY);
    }
    set({ accessToken: token });
  },
  clear: () => {
    localStorage.removeItem(ACCESS_KEY);
    localStorage.removeItem(REFRESH_KEY);
    set({ accessToken: null });
  },
}));

// Доступ к состоянию вне React — используется интерцептором.
export function getAccessToken(): string | null {
  return useAuthStore.getState().accessToken;
}

export function getRefreshToken(): string | null {
  return localStorage.getItem(REFRESH_KEY);
}
```

**3. Инстанс с интерцепторами — `src/api/http.ts`:**

```ts
import axios from 'axios';
import type { AxiosError, InternalAxiosRequestConfig } from 'axios';
import { clearAuth, getAccessToken, getRefreshToken } from '../store/authStore';
import { useAuthStore } from '../store/authStore';
import { normalizeError } from './errors';

// Дополнительные поля конфигурации, которыми пользуются интерцепторы.
// Расширяем AxiosRequestConfig — от него наследуется и внутренняя конфигурация.
declare module 'axios' {
  export interface AxiosRequestConfig {
    // Признак «запрос уже повторяли» — защита от бесконечного цикла.
    _retry?: boolean;
    // Публичный запрос: заголовок Authorization не добавляется.
    skipAuth?: boolean;
  }
}

const baseURL = import.meta.env.VITE_API_URL ?? 'http://localhost:3000/api';

// Основной экземпляр приложения: через него идут все запросы.
export const appApi = axios.create({
  baseURL,
  headers: {
    'Content-Type': 'application/json',
    Accept: 'application/json',
  },
  timeout: 10_000,
});

// Отдельный «чистый» клиент для обновления токена.
// Он не проходит через интерцепторы, поэтому рекурсия невозможна.
const refreshClient = axios.create({
  baseURL,
  headers: { 'Content-Type': 'application/json' },
  timeout: 10_000,
});

// --- Интерцептор запроса ---
const requestInterceptorId = appApi.interceptors.request.use(
  (config) => {
    // Публичные запросы (вход, регистрация) уходят без токена.
    if (!config.skipAuth) {
      const token = getAccessToken();
      if (token) {
        config.headers.Authorization = `Bearer ${token}`;
      }
    }

    const method = config.method?.toUpperCase() ?? 'GET';
    console.info(`→ ${method} ${config.url}`);
    return config;
  },
  (error: AxiosError) => Promise.reject(error),
);

// --- Интерцептор ответа ---
let isRefreshing = false;
// Очередь запросов, ожидающих обновления токена.
let queue: Array<(token: string | null) => void> = [];

function flushQueue(token: string | null): void {
  queue.forEach((resolve) => resolve(token));
  queue = [];
}

const responseInterceptorId = appApi.interceptors.response.use(
  (response) => {
    const method = response.config.method?.toUpperCase() ?? 'GET';
    console.info(`← ${response.status} ${method} ${response.config.url}`);
    return response;
  },
  async (error: AxiosError) => {
    const original = error.config as InternalAxiosRequestConfig | undefined;

    // 401: пробуем обновить токен и повторить исходный запрос ровно один раз.
    if (error.response?.status === 401 && original && !original._retry) {
      original._retry = true;

      // Токен уже обновляется: встаём в очередь и ждём результат.
      if (isRefreshing) {
        return new Promise((resolve, reject) => {
          queue.push((token) => {
            if (!token) {
              reject(error);
              return;
            }
            original.headers.Authorization = `Bearer ${token}`;
            resolve(appApi(original));
          });
        });
      }

      isRefreshing = true;
      try {
        const newToken = await refreshAccessToken();
        flushQueue(newToken);
        original.headers.Authorization = `Bearer ${newToken}`;
        return await appApi(original);
      } catch (refreshError) {
        // Обновить токен не удалось: разлогиниваем и уходим на страницу входа.
        flushQueue(null);
        clearAuth();
        redirectToLogin();
        return Promise.reject(refreshError);
      } finally {
        isRefreshing = false;
      }
    }

    // Все остальные ошибки приводим к единому классу ApiError.
    return Promise.reject(normalizeError(error));
  },
);

// Обновление токена выполняется «чистым» клиентом.
async function refreshAccessToken(): Promise<string> {
  const refreshToken = getRefreshToken();

  if (!refreshToken) {
    throw new Error('Refresh-токен отсутствует');
  }

  const { data } = await refreshClient.post<{ accessToken: string }>('/auth/refresh', {
    refreshToken,
  });

  useAuthStore.getState().setAccessToken(data.accessToken);
  return data.accessToken;
}

// Интерцепторы работают вне React, поэтому редирект выполняем через браузер.
function redirectToLogin(): void {
  if (window.location.pathname !== '/login') {
    window.location.replace('/login');
  }
}

// Отключение интерцепторов через eject.
export function disableRequestInterceptor(): void {
  appApi.interceptors.request.eject(requestInterceptorId);
}

export function disableResponseInterceptor(): void {
  appApi.interceptors.response.eject(responseInterceptorId);
}
```

**4. Сервис авторизации — `src/api/auth.ts`:**

```ts
import { appApi } from './http';

export interface LoginCredentials {
  email: string;
  password: string;
}

export interface User {
  id: number;
  name: string;
  email: string;
}

export interface AuthResponse {
  accessToken: string;
  refreshToken: string;
  user: User;
}

// Публичный запрос: skipAuth отключает добавление заголовка Authorization.
export async function login(credentials: LoginCredentials): Promise<AuthResponse> {
  const { data } = await appApi.post<AuthResponse>('/auth/login', credentials, {
    skipAuth: true,
  });
  return data;
}

// Защищённый запрос: токен подставит интерцептор.
export async function fetchMe(): Promise<User> {
  const { data } = await appApi.get<User>('/auth/me');
  return data;
}
```

**5. Форма входа — `src/components/LoginForm.tsx`:**

```tsx
import { useState } from 'react';
import type { FormEvent } from 'react';
import { useMutation } from '@tanstack/react-query';
import { login } from '../api/auth';
import type { LoginCredentials } from '../api/auth';
import { getErrorMessage } from '../api/errors';
import { useAuthStore } from '../store/authStore';

export function LoginForm() {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const setAccessToken = useAuthStore((state) => state.setAccessToken);

  const mutation = useMutation({
    mutationFn: (credentials: LoginCredentials) => login(credentials),
    onSuccess: (data) => {
      setAccessToken(data.accessToken);
      localStorage.setItem('refresh_token', data.refreshToken);
    },
  });

  function handleSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    mutation.mutate({ email, password });
  }

  return (
    <form onSubmit={handleSubmit}>
      <div>
        <label htmlFor="email">Email</label>
        <input
          id="email"
          type="email"
          value={email}
          onChange={(event) => setEmail(event.target.value)}
          required
        />
      </div>

      <div>
        <label htmlFor="password">Пароль</label>
        <input
          id="password"
          type="password"
          value={password}
          onChange={(event) => setPassword(event.target.value)}
          required
        />
      </div>

      <button type="submit" disabled={mutation.isPending}>
        {mutation.isPending ? 'Вход…' : 'Войти'}
      </button>

      {mutation.isError && <p role="alert">{getErrorMessage(mutation.error)}</p>}
    </form>
  );
}
```

**6. Защищённый запрос — `src/components/MeCard.tsx`:**

```tsx
import { useQuery } from '@tanstack/react-query';
import { fetchMe } from '../api/auth';
import type { User } from '../api/auth';

export function MeCard() {
  const { data, isPending, isError, error } = useQuery<User, Error>({
    queryKey: ['me'],
    queryFn: fetchMe,
  });

  if (isPending) {
    return <p role="status">Загрузка профиля…</p>;
  }

  if (isError) {
    return <p role="alert">{error.message}</p>;
  }

  return (
    <div>
      <p>Имя: {data.name}</p>
      <p>Email: {data.email}</p>
    </div>
  );
}
```

#### src/api/http.ts
```ts
import axios from 'axios';
import type { AxiosError, InternalAxiosRequestConfig } from 'axios';
import { getAccessToken } from '../store/authStore';
import { normalizeError } from './errors';

declare module 'axios' {
  export interface AxiosRequestConfig {
    _retry?: boolean;
    skipAuth?: boolean;
  }
}

export const appApi = axios.create({
  baseURL: import.meta.env.VITE_API_URL ?? 'http://localhost:3000/api',
  headers: { 'Content-Type': 'application/json' },
  timeout: 10_000,
});

// Кэш ответов каталога: адрес запроса -> данные и время создания.
const cache = new Map<string, { data: unknown; createdAt: number }>();
const CACHE_TIME = 5 * 60 * 1000;

appApi.interceptors.request.use((config) => {
  const method = config.method?.toUpperCase();
  const token = getAccessToken();

  // Токен добавляем только к защищённым запросам корзины.
  if (token && !config.skipAuth) {
    config.headers.Authorization = `Bearer ${token}`;
  }

  // Аналитика просмотров: отправляем отдельным запросом, не мешая основному.
  if (method === 'GET' && config.url?.startsWith('/products/')) {
    void axios.post('/analytics/views', { url: config.url });
  }

  return config;
});

appApi.interceptors.response.use(
  (response) => {
    // Кэшируем только успешные GET-запросы каталога.
    if (response.config.method?.toUpperCase() === 'GET' && response.config.url?.startsWith('/products')) {
      cache.set(response.config.url, { data: response.data, createdAt: Date.now() });
    }
    return response;
  },
  async (error: AxiosError) => {
    const original = error.config as InternalAxiosRequestConfig | undefined;
    const status = error.response?.status;

    // Повторяем только временные ошибки, не больше двух раз.
    if (original && !original._retry && (status === undefined || status >= 500)) {
      original._retry = true;
      await new Promise((resolve) => setTimeout(resolve, 1_000));
      return appApi(original);
    }

    return Promise.reject(normalizeError(error));
  },
);

export function getCachedProduct(url: string): unknown | null {
  const entry = cache.get(url);
  if (!entry || Date.now() - entry.createdAt > CACHE_TIME) {
    return null;
  }
  return entry.data;
}
```

#### src/components/ProductCatalog.tsx
```tsx
import { useQuery } from '@tanstack/react-query';
import type { AxiosError } from 'axios';
import { appApi } from '../api/http';
import { getErrorMessage } from '../api/errors';

interface Product {
  id: number;
  title: string;
  price: number;
}

export function ProductCatalog() {
  const { data, isPending, isError, error } = useQuery<Product[], AxiosError>({
    queryKey: ['products'],
    queryFn: async () => {
      const { data: products } = await appApi.get<Product[]>('/products');
      return products;
    },
    staleTime: 5 * 60_000,
  });

  if (isPending) return <p role="status">Загрузка каталога…</p>;
  if (isError) return <p role="alert">{getErrorMessage(error)}</p>;

  return (
    <ul>
      {data.map((product) => (
        <li key={product.id}>
          {product.title} — {product.price} ₽
        </li>
      ))}
    </ul>
  );
}
```
