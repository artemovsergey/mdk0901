# Самостоятельная работа 9. Реализация чата (React + SignalR)

### **Тема:** Разработка чат-приложения реального времени на React и SignalR

### **Цель:**
Научиться проектировать и реализовывать клиент чат-приложения на React 19 + TypeScript, который подключается к SignalR-хабу ASP.NET Core. Освоить управление соединением в пользовательском хуке, работу с комнатами (группами), список участников, хранение истории сообщений в состоянии, индикатор «печатает…» и авторизацию по JWT. Закрепить разделение ответственности: хук отвечает за соединение, компоненты — только за отображение.

---

### **Теоретическая часть:**

**SignalR** — библиотека ASP.NET Core для функциональности реального времени. Она сама выбирает доступный транспорт (WebSocket, Server-Sent Events, Long Polling), берёт на себя переподключение, групповую рассылку и сериализацию. На клиенте используется пакет `@microsoft/signalr`.

```
React-клиент (@microsoft/signalr) ⇄ WebSocket ⇄ ASP.NET Core (SignalR Hub)
```

**Основные понятия SignalR:**
- **Хаб (Hub)** — класс на сервере, методы которого вызываются с клиента, а серверные события приходят на клиент.
- **События** — именованные сообщения между клиентом и хабом (`ReceiveMessage`, `OnlineUsersUpdated`, `TypingUser`).
- **Группы** — логические объединения соединений; в чате группа = комната.
- **Clients** — адресация получателей: `Clients.All`, `Clients.Caller`, `Clients.Others`, `Clients.Group(roomId)`, `Clients.User(userId)`.

**Установка клиента:**
```bash
npm install @microsoft/signalr
```

**Основной API объекта `HubConnection`:**

| Метод / свойство | Назначение |
|------------------|-----------|
| `start()` | Устанавливает соединение (возвращает `Promise`) |
| `stop()` | Закрывает соединение (возвращает `Promise`) |
| `on(method, handler)` | Регистрирует обработчик серверного события |
| `off(method, handler)` | Удаляет конкретный обработчик события |
| `invoke(method, ...args)` | Вызов метода хаба с ожиданием результата и ошибок |
| `send(method, ...args)` | Вызов метода хаба без ожидания результата («выстрелил и забыл») |
| `connection.state` | Текущее состояние (`HubConnectionState`) |
| `onreconnecting(cb)` / `onreconnected(cb)` | Начало и завершение переподключения |
| `onclose(cb)` | Соединение окончательно закрыто |

**Архитектура чата:**
- **Комнаты** — группы SignalR. Клиент вызывает `JoinRoom(roomId)`, сервер выполняет `Groups.AddToGroupAsync(ConnectionId, roomId)` и рассылает сообщения через `Clients.Group(roomId)`. При выходе — `LeaveRoom`.
- **Участники** — список онлайн-пользователей. Сервер пересобирает его в `OnConnectedAsync` / `OnDisconnectedAsync` и рассылает событие `OnlineUsersUpdated`.
- **История сообщений** — хранится на сервере (последние N сообщений на комнату) и отдаётся методом `GetHistory` или сразу при `JoinRoom`. На клиенте история живёт в состоянии React (`useState`), а не в DOM.
- **Индикатор «печатает…»** — при вводе текста клиент вызывает `Typing(roomId)`, сервер рассылает событие `TypingUser` остальным участникам комнаты. Вызовы ограничивают дебаунсом/троттлингом (не чаще раза в секунду), а индикатор автоматически скрывается через пару секунд.
- **Авторизация по JWT** — токен передаётся через `accessTokenFactory` при построении соединения, хаб помечается `[Authorize]`, а имя пользователя берётся из `Context.User`.

**Особенности React.** Соединение создаётся в `useEffect`, а в возвращаемой функции очистки обязательно вызывается `connection.stop()` и `off()` для всех обработчиков. В режиме разработки React 19 (StrictMode) монтирует компоненты дважды, поэтому без очистки останутся «висячие» соединения. Обработчики и функцию получения токена хранят в `useRef`, чтобы они не пересоздавали соединение на каждом рендере; набор обработчиков стабилизируют через `useMemo`.

**Типизация.** В проекте включён `verbatimModuleSyntax`, поэтому типы импортируются отдельно: `import type { HubConnection } from '@microsoft/signalr';`, а значения (классы, перечисления) — обычным импортом: `import { HubConnectionBuilder, HubConnectionState, LogLevel } from '@microsoft/signalr';`.

**5. src/hooks/useSignalR.ts — хук управления соединением:**
```tsx
import { useCallback, useEffect, useRef, useState } from 'react';
import {
  HubConnectionBuilder,
  HubConnectionState,
  LogLevel,
} from '@microsoft/signalr';
import type { HubConnection } from '@microsoft/signalr';

export type ConnectionStatus =
  | 'connecting'
  | 'connected'
  | 'reconnecting'
  | 'disconnected';

// Обработчики серверных событий: ключ — имя метода хаба.
type HubEventHandlers = Record<string, (...args: never[]) => void>;

interface UseSignalROptions {
  url: string;
  handlers: HubEventHandlers;
  getToken?: () => string | null;
  onReconnected?: (connection: HubConnection) => void;
  enabled?: boolean;
}

export function useSignalR({
  url,
  handlers,
  getToken,
  onReconnected,
  enabled = true,
}: UseSignalROptions) {
  const [status, setStatus] = useState<ConnectionStatus>('disconnected');
  const [reconnectKey, setReconnectKey] = useState(0);
  const connectionRef = useRef<HubConnection | null>(null);

  // Актуальные колбэки держим в ref, чтобы не пересоздавать соединение на каждый рендер.
  const handlersRef = useRef(handlers);
  handlersRef.current = handlers;
  const getTokenRef = useRef(getToken);
  getTokenRef.current = getToken;
  const onReconnectedRef = useRef(onReconnected);
  onReconnectedRef.current = onReconnected;

  useEffect(() => {
    if (!enabled) return;

    const connection = new HubConnectionBuilder()
      .withUrl(url, {
        accessTokenFactory: () => getTokenRef.current?.() ?? '',
      })
      .withAutomaticReconnect([0, 2000, 5000, 10000, 30000])
      .configureLogging(LogLevel.Information)
      .build();

    connectionRef.current = connection;

    // 1. Регистрируем обработчики событий сервера.
    // Запоминаем пары «метод — обёртка», чтобы потом снять их через off().
    const boundHandlers = Object.keys(handlersRef.current).map((method) => {
      const handler = (...args: unknown[]) => {
        const current = handlersRef.current[method] as
          | ((...args: unknown[]) => void)
          | undefined;
        current?.(...args);
      };
      connection.on(method, handler);
      return { method, handler };
    });

    // 2. События жизненного цикла соединения.
    connection.onreconnecting((error) => {
      console.warn('SignalR: переподключение...', error);
      setStatus('reconnecting');
    });

    connection.onreconnected(() => {
      setStatus('connected');
      onReconnectedRef.current?.(connection);
    });

    connection.onclose((error) => {
      console.warn('SignalR: соединение закрыто', error);
      setStatus('disconnected');
    });

    // 3. Запуск соединения.
    let cancelled = false;
    setStatus('connecting');
    connection
      .start()
      .then(() => {
        if (!cancelled) setStatus('connected');
      })
      .catch((error: unknown) => {
        if (!cancelled) {
          console.error('SignalR: не удалось подключиться', error);
          setStatus('disconnected');
        }
      });

    // 4. Очистка: снимаем обработчики и останавливаем соединение.
    return () => {
      cancelled = true;
      boundHandlers.forEach(({ method, handler }) => connection.off(method, handler));
      void connection.stop();
      connectionRef.current = null;
    };
  }, [url, enabled, reconnectKey]);

  const invoke = useCallback(async (method: string, ...args: unknown[]) => {
    const connection = connectionRef.current;
    if (!connection || connection.state !== HubConnectionState.Connected) {
      console.warn(`SignalR: метод ${method} пропущен — нет соединения`);
      return undefined;
    }
    return connection.invoke(method, ...args);
  }, []);

  const send = useCallback(async (method: string, ...args: unknown[]) => {
    const connection = connectionRef.current;
    if (!connection || connection.state !== HubConnectionState.Connected) {
      console.warn(`SignalR: метод ${method} пропущен — нет соединения`);
      return;
    }
    await connection.send(method, ...args);
  }, []);

  const reconnect = useCallback(() => setReconnectKey((key) => key + 1), []);

  return { status, invoke, send, reconnect };
}
```

**8. src/components/MessageInput.tsx — форма отправки:**
```tsx
import { useState } from 'react';
import type { FormEvent } from 'react';

interface MessageInputProps {
  disabled: boolean;
  onSend: (text: string) => Promise<void>;
  onTyping: () => void;
}

export function MessageInput({ disabled, onSend, onTyping }: MessageInputProps) {
  const [text, setText] = useState('');
  const [isSending, setIsSending] = useState(false);

  const handleChange = (value: string) => {
    setText(value);
    onTyping();
  };

  const handleSubmit = async (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    const trimmed = text.trim();
    if (!trimmed || isSending) return;

    setIsSending(true);
    try {
      await onSend(trimmed);
      setText('');
    } finally {
      setIsSending(false);
    }
  };

  return (
    <form className="message-form" onSubmit={handleSubmit}>
      <label className="sr-only" htmlFor="message-text">
        Текст сообщения
      </label>
      <input
        id="message-text"
        className="message-input"
        type="text"
        value={text}
        onChange={(event) => handleChange(event.target.value)}
        placeholder="Введите сообщение..."
        autoComplete="off"
        disabled={disabled}
      />
      <button
        className="send-button"
        type="submit"
        disabled={disabled || isSending || text.trim().length === 0}
      >
        {isSending ? 'Отправка…' : 'Отправить'}
      </button>
    </form>
  );
}
```

**9. src/components/ChatRoom.tsx — соединение и интерфейс комнаты:**
```tsx
import { useCallback, useEffect, useMemo, useRef, useState } from 'react';
import type { ChatMessage, OnlineUser, TypingNotification } from '../types/chat';
import { HUB_URL } from '../lib/hub';
import { useSignalR } from '../hooks/useSignalR';
import { MessageList } from './MessageList';
import { MessageInput } from './MessageInput';
import { UsersList } from './UsersList';

interface ChatRoomProps {
  roomId: string;
  currentUser: string;
}

export function ChatRoom({ roomId, currentUser }: ChatRoomProps) {
  const [messages, setMessages] = useState<ChatMessage[]>([]);
  const [users, setUsers] = useState<OnlineUser[]>([]);
  const [typingUser, setTypingUser] = useState<string | null>(null);
  const lastTypingRef = useRef(0);

  // Набор обработчиков серверных событий. Ключи совпадают с именами методов хаба.
  const handlers = useMemo(
    () => ({
      ReceiveMessage: (message: ChatMessage) => {
        setMessages((prev) => [...prev, message]);
      },
      MessageHistory: (history: ChatMessage[]) => {
        setMessages(history);
      },
      OnlineUsersUpdated: (online: OnlineUser[]) => {
        setUsers(online);
      },
      TypingUser: (notification: TypingNotification) => {
        setTypingUser(notification.isTyping ? notification.user : null);
      },
    }),
    [],
  );

  const { status, invoke, reconnect } = useSignalR({
    url: HUB_URL,
    handlers,
    getToken: () => localStorage.getItem('access_token'),
  });

  // После подключения и после каждого переподключения заново входим в комнату:
  // серверные группы при разрыве соединения теряются.
  useEffect(() => {
    if (status === 'connected') {
      void invoke('JoinRoom', roomId);
    }
  }, [status, roomId, invoke]);

  const handleSend = useCallback(
    async (text: string) => {
      await invoke('SendMessage', roomId, currentUser, text);
    },
    [invoke, roomId, currentUser],
  );

  // Не чаще одного вызова в секунду, чтобы не заваливать хаб событием набора текста.
  const handleTyping = useCallback(() => {
    const now = Date.now();
    if (now - lastTypingRef.current < 1000) return;
    lastTypingRef.current = now;
    void invoke('Typing', roomId, currentUser);
  }, [invoke, roomId, currentUser]);

  return (
    <section className="chat-room">
      <header className="chat-room-header">
        <h1>Комната: {roomId}</h1>
        <span
          className={`status status-${status}`}
          role="status"
          aria-live="polite"
        >
          {status === 'connected' ? 'На связи' : 'Нет связи'}
        </span>
        {status === 'disconnected' && (
          <button type="button" className="reconnect-button" onClick={reconnect}>
            Подключиться
          </button>
        )}
      </header>

      <div className="chat-room-body">
        <MessageList
          messages={messages}
          currentUser={currentUser}
          typingUser={typingUser}
        />
        <UsersList users={users} currentUser={currentUser} />
      </div>

      <MessageInput
        disabled={status !== 'connected'}
        onSend={handleSend}
        onTyping={handleTyping}
      />
    </section>
  );
}
```

**13. Серверная часть (справочно).** Клиент ожидает от хаба события `ReceiveMessage`, `MessageHistory`, `OnlineUsersUpdated`, `TypingUser` и вызывает методы `JoinRoom`, `LeaveRoom`, `SendMessage`, `Typing`, `GetHistory`. Минимальный хаб на ASP.NET Core:

```csharp
[Authorize]
public class ChatHub : Hub
{
    // История последних сообщений по комнатам (в учебном примере — в памяти).
    private static readonly ConcurrentDictionary<string, List<ChatMessageDto>> History = new();
    private static readonly ConcurrentDictionary<string, string> OnlineUsers = new();

    public override async Task OnConnectedAsync()
    {
        var nickname = Context.User?.Identity?.Name ?? $"Гость-{Context.ConnectionId[..4]}";
        OnlineUsers[Context.ConnectionId] = nickname;
        await Clients.All.SendAsync("OnlineUsersUpdated", ToOnlineList());
        await base.OnConnectedAsync();
    }

    public override async Task OnDisconnectedAsync(Exception? exception)
    {
        OnlineUsers.TryRemove(Context.ConnectionId, out _);
        await Clients.All.SendAsync("OnlineUsersUpdated", ToOnlineList());
        await base.OnDisconnectedAsync(exception);
    }

    public async Task JoinRoom(string roomId)
    {
        await Groups.AddToGroupAsync(Context.ConnectionId, roomId);
        await Clients.Caller.SendAsync("MessageHistory", GetHistory(roomId));
    }

    public Task LeaveRoom(string roomId) =>
        Groups.RemoveFromGroupAsync(Context.ConnectionId, roomId);

    public Task SendMessage(string roomId, string user, string text)
    {
        var message = new ChatMessageDto(
            Guid.NewGuid().ToString(), roomId, user, text, DateTime.UtcNow.ToString("o"));
        GetHistory(roomId).Add(message);
        return Clients.Group(roomId).SendAsync("ReceiveMessage", message);
    }

    // Второму участнику комнаты показываем «печатает…».
    public Task Typing(string roomId, string user) =>
        Clients.OthersInGroup(roomId).SendAsync("TypingUser",
            new { RoomId = roomId, User = user, IsTyping = true });

    public Task GetHistory(string roomId) =>
        Clients.Caller.SendAsync("MessageHistory", GetHistory(roomId));

    private static List<ChatMessageDto> GetHistory(string roomId) =>
        History.GetOrAdd(roomId, _ => new List<ChatMessageDto>());

    private static object ToOnlineList() => OnlineUsers
        .Select(u => new { ConnectionId = u.Key, Nickname = u.Value })
        .ToList();
}
```

````markdown
### src/hooks/useSignalR.ts
```tsx
import { useCallback, useEffect, useRef, useState } from 'react';
import { HubConnectionBuilder, HubConnectionState, LogLevel } from '@microsoft/signalr';
import type { HubConnection } from '@microsoft/signalr';

export type ConnectionStatus =
  | 'connecting'
  | 'connected'
  | 'reconnecting'
  | 'disconnected';

type HubEventHandlers = Record<string, (...args: never[]) => void>;

interface UseSignalROptions {
  url: string;
  handlers: HubEventHandlers;
  getToken?: () => string | null;
}

export function useSignalR({ url, handlers, getToken }: UseSignalROptions) {
  const [status, setStatus] = useState<ConnectionStatus>('disconnected');
  const connectionRef = useRef<HubConnection | null>(null);
  const handlersRef = useRef(handlers);
  handlersRef.current = handlers;

  useEffect(() => {
    const connection = new HubConnectionBuilder()
      .withUrl(url, { accessTokenFactory: () => getToken?.() ?? '' })
      .withAutomaticReconnect([0, 2000, 5000, 10000, 30000])
      .configureLogging(LogLevel.Information)
      .build();

    connectionRef.current = connection;

    const boundHandlers = Object.keys(handlersRef.current).map((method) => {
      const handler = (...args: unknown[]) => {
        const current = handlersRef.current[method] as
          | ((...args: unknown[]) => void)
          | undefined;
        current?.(...args);
      };
      connection.on(method, handler);
      return { method, handler };
    });

    connection.onreconnecting(() => setStatus('reconnecting'));
    connection.onreconnected(() => setStatus('connected'));
    connection.onclose(() => setStatus('disconnected'));

    setStatus('connecting');
    connection
      .start()
      .then(() => setStatus('connected'))
      .catch((error: unknown) => {
        console.error('SignalR: не удалось подключиться', error);
        setStatus('disconnected');
      });

    return () => {
      boundHandlers.forEach(({ method, handler }) => connection.off(method, handler));
      void connection.stop();
      connectionRef.current = null;
    };
  }, [url, getToken]);

  const invoke = useCallback(async (method: string, ...args: unknown[]) => {
    const connection = connectionRef.current;
    if (!connection || connection.state !== HubConnectionState.Connected) return;
    return connection.invoke(method, ...args);
  }, []);

  return { status, invoke };
}
```

### src/components/ChatRoom.tsx
```tsx
import { useCallback, useEffect, useMemo, useState } from 'react';
import type { ChatMessage, OnlineUser } from '../types/chat';
import { HUB_URL } from '../lib/hub';
import { useSignalR } from '../hooks/useSignalR';
import { MessageList } from './MessageList';
import { MessageInput } from './MessageInput';
import { UsersList } from './UsersList';

interface ChatRoomProps {
  roomId: string;
  currentUser: string;
}

export function ChatRoom({ roomId, currentUser }: ChatRoomProps) {
  const [messages, setMessages] = useState<ChatMessage[]>([]);
  const [users, setUsers] = useState<OnlineUser[]>([]);

  const handlers = useMemo(
    () => ({
      ReceiveMessage: (message: ChatMessage) =>
        setMessages((prev) => [...prev, message]),
      OnlineUsersUpdated: (online: OnlineUser[]) => setUsers(online),
    }),
    [],
  );

  const { status, invoke } = useSignalR({
    url: HUB_URL,
    handlers,
    getToken: () => localStorage.getItem('access_token'),
  });

  useEffect(() => {
    if (status === 'connected') void invoke('JoinRoom', roomId);
  }, [status, roomId, invoke]);

  const handleSend = useCallback(
    async (text: string) => {
      await invoke('SendMessage', roomId, currentUser, text);
    },
    [invoke, roomId, currentUser],
  );

  return (
    <section className="chat-room">
      <h1>Комната: {roomId}</h1>
      <MessageList messages={messages} currentUser={currentUser} typingUser={null} />
      <UsersList users={users} currentUser={currentUser} />
      <MessageInput
        disabled={status !== 'connected'}
        onSend={handleSend}
        onTyping={() => undefined}
      />
    </section>
  );
}
````
