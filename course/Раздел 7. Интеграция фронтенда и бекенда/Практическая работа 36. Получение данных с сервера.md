# Практическая работа 36. Получение данных с сервера

### **Тема:** Получение данных с сервера в React — Axios и TanStack Query

### **Цель:**
Научиться выполнять HTTP-запросы к серверу с помощью Axios и управлять серверным состоянием в React-приложении с помощью TanStack Query. Освоить хук `useQuery`, состояния загрузки, ошибки и успеха, повторный запрос данных, кэширование и параметризованные запросы.

### **Теоретическая часть:**

**Как React-приложение получает данные.** Компонент сам не «ходит» в сеть. Запросы выполняет отдельный слой — модуль API. Компонент вызывает типизированную функцию и получает результат. Такое разделение делает код предсказуемым: сетевую логику можно менять, не трогая интерфейс.

**Axios-инстанс.** Вместо того чтобы каждый раз писать полный адрес сервера, создают один настроенный экземпляр Axios:

```ts
import axios from 'axios';

export const http = axios.create({
  baseURL: import.meta.env.VITE_API_URL,
  timeout: 10_000,
});
```

*   `baseURL` берётся из переменной окружения Vite (`import.meta.env.VITE_API_URL`), поэтому один и тот же код работает и с тестовым сервером, и с боевым;
*   `timeout` задаёт предельное время ожидания ответа;
*   общие заголовки (`Content-Type`, `Accept`) указываются один раз в `headers`.

Vite читает переменные окружения только с префиксом `VITE_` из файла `.env` в корне проекта.

**TanStack Query и серверное состояние.** Данные с сервера называют **серверным состоянием**: они хранятся на сервере, могут устареть и требуют кэша. Хук `useQuery` берёт на себя загрузку, кэширование, повторные запросы и синхронизацию. Разработчик описывает только то, *что* загружать.

Основные параметры `useQuery`:

| Параметр | Назначение |
|---|---|
| `queryKey` | Массив — ключ записи в кэше. Включает переменные запроса |
| `queryFn` | Функция, возвращающая промис с данными |
| `staleTime` | Сколько миллисекунд данные считаются свежими |
| `enabled` | Включает или выключает запрос |
| `retry` | Сколько раз повторить запрос при ошибке |

**Статусы запроса:**

| Свойство | Что означает |
|---|---|
| `isPending` | Данных ещё нет, запрос выполняется впервые |
| `isSuccess` | Данные успешно получены |
| `isError` | Запрос завершился ошибкой |
| `isFetching` | Идёт любой запрос, включая фоновое обновление |
| `refetch` | Функция для повторного запроса вручную |

`isPending` и `isFetching` важно различать: при повторном запросе данные уже есть, поэтому `isPending` равен `false`, а `isFetching` — `true`. Это позволяет показывать надпись «Обновление…», не скрывая уже загруженный список.

**Параметризованные запросы.** Если запрос зависит от переменной (номер страницы, идентификатор записи, поисковая строка), её добавляют в `queryKey`. При изменении ключа TanStack Query выполняет новый запрос и кэширует результат отдельно. Параметр `enabled` позволяет не отправлять запрос, пока переменная не готова (например, пользователь ещё не выбрал запись).

### **Ход работы:**

1. Создать React-проект (Vite + TypeScript) и установить `axios`, `@tanstack/react-query`, `@tanstack/react-query-devtools`.

### **Практический пример:**

**1. Установка зависимостей и точка входа — `src/main.tsx`:**

```bash
npm install axios @tanstack/react-query
npm install -D @tanstack/react-query-devtools
```

```tsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { ReactQueryDevtools } from '@tanstack/react-query-devtools';
import './index.css';
import App from './App.tsx';

// Один клиент кэша на всё приложение.
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      // Данные считаются свежими 60 секунд.
      staleTime: 60_000,
      // Несвежие данные хранятся в памяти 5 минут.
      gcTime: 5 * 60_000,
      // Не перезапрашивать данные при возврате фокуса в окно.
      refetchOnWindowFocus: false,
      // Один автоматический повтор при ошибке.
      retry: 1,
    },
  },
});

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <QueryClientProvider client={queryClient}>
      <App />
      <ReactQueryDevtools initialIsOpen={false} />
    </QueryClientProvider>
  </StrictMode>,
);
```

**4. Типизированные функции запросов — `src/api/posts.ts`:**

```ts
import { http } from './http';

export interface Post {
  id: number;
  userId: number;
  title: string;
  body: string;
}

export interface User {
  id: number;
  name: string;
  email: string;
}

// Список записей: сервер ограничивает выдачу двенадцатью элементами.
export async function fetchPosts(): Promise<Post[]> {
  const { data } = await http.get<Post[]>('/posts', {
    params: { _limit: 12 },
  });
  return data;
}

// Одна запись по идентификатору.
export async function fetchPostById(id: number): Promise<Post> {
  const { data } = await http.get<Post>(`/posts/${id}`);
  return data;
}

// Список пользователей.
export async function fetchUsers(): Promise<User[]> {
  const { data } = await http.get<User[]>('/users');
  return data;
}
```

**5. Каталог с `useQuery` — `src/components/PostsCatalog.tsx`:**

```tsx
import { useQuery } from '@tanstack/react-query';
import { fetchPosts } from '../api/posts';
import type { Post } from '../api/posts';

interface PostsCatalogProps {
  selectedId: number | null;
  onSelect: (id: number) => void;
}

export function PostsCatalog({ selectedId, onSelect }: PostsCatalogProps) {
  const {
    data,
    isPending,
    isError,
    isSuccess,
    error,
    isFetching,
    refetch,
  } = useQuery<Post[], Error>({
    queryKey: ['posts'],
    queryFn: fetchPosts,
    staleTime: 30_000,
  });

  // Первая загрузка: данных ещё нет.
  if (isPending) {
    return <p role="status">Загрузка записей…</p>;
  }

  // Ошибка запроса: показываем сообщение и кнопку повтора.
  if (isError) {
    return (
      <div role="alert">
        <p>Не удалось загрузить записи: {error.message}</p>
        <button type="button" onClick={() => void refetch()}>
          Повторить
        </button>
      </div>
    );
  }

  // Пустой список.
  if (isSuccess && data.length === 0) {
    return <p>Записей пока нет.</p>;
  }

  return (
    <section>
      <header>
        <h2>Записи</h2>
        <button
          type="button"
          onClick={() => void refetch()}
          disabled={isFetching}
        >
          {isFetching ? 'Обновление…' : 'Обновить'}
        </button>
      </header>

      <ul>
        {data.map((post) => (
          <li key={post.id}>
            <button
              type="button"
              onClick={() => onSelect(post.id)}
              aria-current={post.id === selectedId}
            >
              {post.title}
            </button>
          </li>
        ))}
      </ul>
    </section>
  );
}
```

**6. Детальная страница с параметризованным запросом — `src/components/PostDetails.tsx`:**

```tsx
import { useQuery } from '@tanstack/react-query';
import { fetchPostById } from '../api/posts';
import type { Post } from '../api/posts';

interface PostDetailsProps {
  postId: number | null;
}

export function PostDetails({ postId }: PostDetailsProps) {
  const { data, isPending, isError, error } = useQuery<Post, Error>({
    // Идентификатор входит в ключ кэша: каждая запись кэшируется отдельно.
    queryKey: ['post', postId],
    queryFn: () => {
      if (postId === null) {
        throw new Error('Запись не выбрана');
      }
      return fetchPostById(postId);
    },
    // Запрос выполняется только тогда, когда запись выбрана.
    enabled: postId !== null,
    staleTime: 60_000,
  });

  if (postId === null) {
    return <p>Выберите запись из списка, чтобы увидеть подробности.</p>;
  }

  if (isPending) {
    return <p role="status">Загрузка подробностей…</p>;
  }

  if (isError) {
    return <p role="alert">Ошибка: {error.message}</p>;
  }

  return (
    <article>
      <h2>{data.title}</h2>
      <p>{data.body}</p>
      <p>Автор (userId): {data.userId}</p>
    </article>
  );
}
```

**7. Корневой компонент — `src/App.tsx`:**

```tsx
import { useState } from 'react';
import './App.css';
import { PostsCatalog } from './components/PostsCatalog';
import { PostDetails } from './components/PostDetails';

function App() {
  // Клиентское состояние: выбранная запись хранится в компоненте.
  const [selectedId, setSelectedId] = useState<number | null>(null);

  return (
    <div className="app">
      <h1>Каталог записей</h1>
      <div className="layout">
        <PostsCatalog selectedId={selectedId} onSelect={setSelectedId} />
        <PostDetails postId={selectedId} />
      </div>
    </div>
  );
}

export default App;
```

## Вариант 1: Список постов с пагинацией

### Задание:
Создать приложение для отображения списка постов с JSONPlaceholder API с пагинацией кнопками «Назад» и «Вперёд». Пока грузится новая страница, показывать данные предыдущей.

### Реализация:

#### src/api/http.ts
```ts
import axios from 'axios';

export const http = axios.create({
  baseURL: import.meta.env.VITE_API_URL ?? 'https://jsonplaceholder.typicode.com',
  headers: { 'Content-Type': 'application/json' },
  timeout: 10_000,
});
```

#### src/api/posts.ts
```ts
import { http } from './http';

export interface Post {
  id: number;
  userId: number;
  title: string;
  body: string;
}

const PAGE_SIZE = 10;

export async function fetchPostsPage(page: number): Promise<Post[]> {
  const { data } = await http.get<Post[]>('/posts', {
    params: { _page: page, _limit: PAGE_SIZE },
  });
  return data;
}
```

#### src/components/PostsPagination.tsx
```tsx
import { useState } from 'react';
import { keepPreviousData, useQuery } from '@tanstack/react-query';
import { fetchPostsPage } from '../api/posts';
import type { Post } from '../api/posts';

export function PostsPagination() {
  const [page, setPage] = useState(1);

  const {
    data,
    isPending,
    isError,
    error,
    isFetching,
    isPlaceholderData,
  } = useQuery<Post[], Error>({
    // Номер страницы входит в ключ кэша.
    queryKey: ['posts', page],
    queryFn: () => fetchPostsPage(page),
    // Пока грузится новая страница, показываем данные предыдущей.
    placeholderData: keepPreviousData,
    staleTime: 30_000,
  });

  if (isPending) {
    return <p role="status">Загрузка постов…</p>;
  }

  if (isError) {
    return <p role="alert">Ошибка: {error.message}</p>;
  }

  return (
    <section>
      <h2>Список постов</h2>
      {isFetching && <p>Обновление…</p>}

      <ul>
        {data.map((post) => (
          <li key={post.id}>
            <h3>{post.title}</h3>
            <p>{post.body}</p>
          </li>
        ))}
      </ul>

      <div className="pagination">
        <button
          type="button"
          onClick={() => setPage((current) => Math.max(current - 1, 1))}
          disabled={page === 1 || isFetching}
        >
          Назад
        </button>
        <span>Страница {page}</span>
        <button
          type="button"
          onClick={() => setPage((current) => current + 1)}
          disabled={isPlaceholderData || isFetching}
        >
          Вперёд
        </button>
      </div>
    </section>
  );
}
```

## **Инструкция по сдаче работы:**

1. Создать репозиторий на Gogs: http://192.168.4.90/
2. Клонировать репозиторий локально
3. Создать React-проект в папке репозитория:
   ```bash
   npm create vite@latest . -- --template react-ts
   npm install
   npm install axios @tanstack/react-query
   npm install -D @tanstack/react-query-devtools
   ```
4. Реализовать функциональность согласно варианту задания
5. Сделать коммиты с понятными сообщениями
