# Практическая работа 16. Условный рендеринг и списки

### **Тема:** Условный вывод и рендеринг списков в React

### **Цель:**
Научиться управлять отображением интерфейса в зависимости от условий и выводить коллекции данных в React. Освоить логический оператор `&&`, тернарный оператор, возврат `null`, метод `map()` с атрибутом `key`, фильтрацию массивов и пустые состояния.

### **Теоретическая часть:**

**Условный рендеринг** — это механизм отображения разных частей интерфейса в зависимости от условий. В React нет отдельного шаблонного языка: условия записываются обычным JavaScript внутри фигурных скобок `{ }`. Всё, что является выражением JavaScript, можно использовать прямо в JSX.

**1. Логическое И (`&&`) — «показать, если истина»:**
```tsx
{isLoading && <p>Загрузка...</p>}
```
Работает так: если левый операнд falsy (`false`, `null`, `undefined`, `0`, `''`), React ничего не рендерит. Если truthy — рендерит правый операнд.

> **Важно:** число `0` — это falsy-значение, но React его выведет на экран! `{items.length && <List />}` при пустом массиве покажет «0». Поэтому условие всегда делают булевым: `{items.length > 0 && <List />}`.

**2. Тернарный оператор — «или одно, или другое»:**
```tsx
{isLoggedIn ? <UserMenu /> : <LoginButton />}
```
Используется, когда нужны оба варианта. Если вариантов три и больше — тернарник лучше не вкладывать, а вынести логику в переменную или функцию.

**3. `null`, `undefined`, `false` не рендерятся:**
```tsx
function UserBadge({ user }: { user: User | null }) {
  if (!user) {
    return null; // React не создаст никакой DOM
  }

  return <span>{user.name}</span>;
}
```
Ранний выход `return null` — удобный способ вообще не выводить компонент.

**4. Рендеринг списков — `map()`:**
```tsx
const fruits = ['Яблоко', 'Груша', 'Слива'];

<ul>
  {fruits.map((fruit) => (
    <li key={fruit}>{fruit}</li>
  ))}
</ul>
```

**5. Атрибут `key`:**
- `key` помогает React понять, какой элемент списка изменился, добавился или удалился.
- `key` должен быть **стабильным и уникальным** — лучше всего подходит `id` из данных.
- **Индекс массива как `key`** — плохая практика, если список меняется (удаление, сортировка, вставка), потому что React перепутает элементы и потеряет состояние.
- `key` указывается только на **верхнем** элементе, который возвращает `map`.

**6. Фильтрация — сначала `filter()`, потом `map()`:**
```tsx
{books
  .filter((book) => book.category === selectedCategory)
  .map((book) => (
    <BookCard key={book.id} book={book} />
  ))}
```

**7. Пустое состояние:**
```tsx
{filtered.length === 0 ? (
  <p className="empty">По вашему запросу ничего не найдено</p>
) : (
  <div className="grid">
    {filtered.map((item) => (
      <Card key={item.id} item={item} />
    ))}
  </div>
)}
```

**8. Fragment с ключом — несколько элементов без лишней обёртки:**
```tsx
import { Fragment } from 'react';

{rows.map((row) => (
  <Fragment key={row.id}>
    <dt>{row.term}</dt>
    <dd>{row.definition}</dd>
  </Fragment>
))}
```
Сокращённая запись `<>...</>` **не принимает** `key`, поэтому для списков нужен явный `<Fragment key={...}>`.

**9. Вместо длинных цепочек условий — словарь или функция:**
```tsx
type Status = 'active' | 'blocked' | 'pending';

const STATUS_LABEL: Record<Status, string> = {
  active: 'Активен',
  blocked: 'Заблокирован',
  pending: 'Ожидает',
};

<span>{STATUS_LABEL[user.status]}</span>
```

**Правила и антипаттерны:**
- Не вкладывать тернарный оператор в тернарный оператор — читаемость падает. Вынесите в переменную или отдельный компонент.
- Слева от `&&` всегда должно быть булево выражение (`length > 0`, `Boolean(value)`).
- `key` — только стабильный `id`, а не индекс.
- Тяжёлую фильтрацию/сортировку в больших списках выносят в `useMemo` (подробно — в следующих лекциях).
- Общую «раскладку» (layout, заголовки, контейнеры) и условные элементы (бейджи, статусы) держат в отдельных компонентах.

5. **src/components/BookCatalog.tsx — список, фильтр и пустое состояние:**
```tsx
import { useState } from 'react';
import { books } from '../data/books';
import type { BookCategory } from '../data/books';
import { BookCard } from './BookCard';

type CategoryFilter = 'all' | BookCategory;

const CATEGORIES: { value: CategoryFilter; label: string }[] = [
  { value: 'all', label: 'Все категории' },
  { value: 'programming', label: 'Программирование' },
  { value: 'design', label: 'Дизайн' },
  { value: 'management', label: 'Менеджмент' },
  { value: 'fiction', label: 'Художественная литература' },
];

export function BookCatalog() {
  const [category, setCategory] = useState<CategoryFilter>('all');
  const [query, setQuery] = useState('');

  const normalizedQuery = query.trim().toLowerCase();

  // Фильтрация выполняется ДО map()
  const filteredBooks = books.filter((book) => {
    const matchesCategory = category === 'all' || book.category === category;
    const matchesQuery = book.title.toLowerCase().includes(normalizedQuery);
    return matchesCategory && matchesQuery;
  });

  return (
    <section className="catalog">
      <h2 className="catalog__title">Каталог книг</h2>

      <div className="catalog__filters">
        <input
          type="search"
          value={query}
          onChange={(event) => setQuery(event.target.value)}
          placeholder="Поиск по названию"
          aria-label="Поиск книг по названию"
        />

        <select
          value={category}
          onChange={(event) => setCategory(event.target.value as CategoryFilter)}
          aria-label="Категория книг"
        >
          {CATEGORIES.map((item) => (
            <option key={item.value} value={item.value}>
              {item.label}
            </option>
          ))}
        </select>
      </div>

      <p className="catalog__count">Найдено книг: {filteredBooks.length}</p>

      {filteredBooks.length === 0 ? (
        <p className="catalog__empty">По вашему запросу ничего не найдено</p>
      ) : (
        <div className="catalog__grid">
          {filteredBooks.map((book) => (
            <BookCard key={book.id} book={book} />
          ))}
        </div>
      )}
    </section>
  );
}
```

**Как это работает:**
- `BookCard` показывает один объект. Он не знает, откуда пришли данные, — просто получает `book` через props.
- `BookCatalog` хранит состояние фильтров и делает `filter()` → `map()`.
- `key={book.id}` сообщает React, какой именно элемент списка изменился.
- Если после фильтрации массив пуст, выводится понятное сообщение вместо пустой сетки.
- Бейджи появляются условно: `&&` для «Новинки», тернарный оператор — для наличия.

**src/components/AuthSystem.tsx:**
```tsx
import { useState } from 'react';
import './AuthSystem.css';

type UserRole = 'guest' | 'user' | 'admin';

interface AuthState {
  isLoggedIn: boolean;
  role: UserRole;
  userName: string;
  isLoading: boolean;
}

const INITIAL_STATE: AuthState = {
  isLoggedIn: false,
  role: 'guest',
  userName: '',
  isLoading: false,
};

const USER_FEATURES = ['Мой профиль', 'Мои заказы', 'Избранное'];
const ADMIN_FEATURES = [
  'Управление пользователями',
  'Статистика',
  'Настройки системы',
  'Модерация контента',
];

export function AuthSystem() {
  const [auth, setAuth] = useState<AuthState>(INITIAL_STATE);

  const loginAs = (role: Exclude<UserRole, 'guest'>) => {
    setAuth((prev) => ({ ...prev, isLoading: true }));

    // Имитация асинхронного запроса
    window.setTimeout(() => {
      setAuth({
        isLoggedIn: true,
        role,
        userName: role === 'admin' ? 'Администратор' : 'Иван Петров',
        isLoading: false,
      });
    }, 800);
  };

  const logout = () => setAuth(INITIAL_STATE);

  if (auth.isLoading) {
    return (
      <div className="auth__loading">
        <div className="auth__spinner" />
        <p>Выполняется вход...</p>
      </div>
    );
  }

  if (!auth.isLoggedIn) {
    return (
      <div className="auth__guest">
        <h3>Добро пожаловать!</h3>
        <p>Пожалуйста, войдите в систему</p>

        <div className="auth__buttons">
          <button type="button" onClick={() => loginAs('user')}>
            Войти как пользователь
          </button>
          <button type="button" onClick={() => loginAs('admin')}>
            Войти как администратор
          </button>
        </div>
      </div>
    );
  }

  const features = auth.role === 'admin' ? ADMIN_FEATURES : USER_FEATURES;

  return (
    <div className="auth__panel">
      <header className="auth__header">
        <h3>Добро пожаловать, {auth.userName}!</h3>
        <button type="button" className="auth__logout" onClick={logout}>
          Выйти
        </button>
      </header>

      {auth.role === 'admin' && <p className="auth__notice">Режим администратора</p>}

      <ul className="auth__features">
        {features.map((feature) => (
          <li key={feature} className={`auth__feature auth__feature--${auth.role}`}>
            {feature}
          </li>
        ))}
      </ul>
    </div>
  );
}
```
