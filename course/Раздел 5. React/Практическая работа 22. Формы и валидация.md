# Практическая работа 22. Формы и валидация

### **Тема:** Формы и валидация в React: react-hook-form и zod

### **Цель:**
Научиться создавать формы в React с помощью библиотеки `react-hook-form` и описывать правила валидации схемами `zod`. Освоить связку через `@hookform/resolvers/zod`, вывод сообщений об ошибках на русском языке, работу с состояниями отправки и сброса формы, а также валидацию взаимозависимых полей.

### **Теоретическая часть:**

**Проблема ручных форм.** Если хранить значения полей в `useState`, то на каждое нажатие клавиши перерисовывается весь компонент, а код быстро разрастается: обработчики, проверки, вывод ошибок. Библиотека `react-hook-form` решает это: она работает с неконтролируемыми полями через `ref`, поэтому лишних перерисовок нет.

**Основные понятия react-hook-form:**
- `useForm` — хук, который создаёт форму и возвращает методы управления;
- `register('fieldName')` — подключает поле к форме (передаёт `ref`, `name`, `onChange`);
- `handleSubmit(onSubmit)` — обёртка над отправкой: сначала проверяет форму, затем вызывает ваш обработчик;
- `formState.errors` — объект с ошибками полей;
- `formState.isSubmitting` — `true` во время асинхронной отправки;
- `watch('fieldName')` — подписка на значение поля;
- `reset()` — сброс формы к исходным значениям;
- `setError('field', { message })` — ручная установка ошибки (например, с ответа сервера).

**Минимальная форма:**
```tsx
import { useForm } from 'react-hook-form';

interface LoginValues {
  email: string;
  password: string;
}

export function LoginForm() {
  const { register, handleSubmit, formState } = useForm<LoginValues>({
    defaultValues: { email: '', password: '' },
  });

  function onSubmit(values: LoginValues) {
    console.log(values);
  }

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input {...register('email')} />
      {formState.errors.email && <span>{formState.errors.email.message}</span>}
      <input type="password" {...register('password')} />
      <button type="submit">Войти</button>
    </form>
  );
}
```

**Зачем нужен zod.** `react-hook-form` не задаёт правил валидации сам. Их описывают схемой `zod`, а `zodResolver` связывает схему с формой. Одна схема — единый источник правил, ей можно пользоваться и на сервере, и на клиенте.

**Схема и вывод типа:**
```ts
import { z } from 'zod';

export const registrationSchema = z.object({
  name: z.string().min(2, 'Имя должно содержать минимум 2 символа'),
  email: z.email('Введите корректный email'),
  password: z.string().min(8, 'Пароль должен содержать минимум 8 символов'),
});

export type RegistrationValues = z.infer<typeof registrationSchema>;
```
`z.infer<typeof schema>` автоматически выводит TypeScript-тип из схемы — дублировать интерфейс не нужно.

**Основные правила zod:**
- `z.string()`, `z.number()`, `z.boolean()` — базовые типы;
- `.min()`, `.max()`, `.length()` — длина строки или число;
- `z.email()`, `z.url()` — строковые форматы (в zod 4 это отдельные функции);
- `.optional()`, `.nullable()` — необязательные значения;
- `z.enum(['a', 'b'])` — перечисление;
- `.refine(...)` — кастомная проверка, в том числе для нескольких полей сразу.

**Валидация взаимозависимых полей.** Для проверки, что пароль и подтверждение совпадают, схему дополняют через `.refine`, а путь ошибки (`path`) указывают так, чтобы ошибка отобразилась у нужного поля:
```ts
export const schema = z
  .object({
    password: z.string().min(8, 'Пароль должен содержать минимум 8 символов'),
    confirmPassword: z.string(),
  })
  .refine((data) => data.password === data.confirmPassword, {
    error: 'Пароли не совпадают',
    path: ['confirmPassword'],
  });
```

**Подключение resolver:**
```tsx
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';

const form = useForm<RegistrationValues>({
  resolver: zodResolver(registrationSchema),
  defaultValues: { name: '', email: '', password: '' },
});
```

**Отображение ошибок.** Сообщение выводится под полем и связывается с ним через `aria-invalid` и `aria-describedby` — так ошибку озвучит скринридер. Тексты ошибок пишут на русском, коротко и понятно.

**Кнопка отправки.** На время отправки её отключают (`disabled={isSubmitting}`) и показывают текст «Отправка…», чтобы пользователь не отправил форму дважды.

**Асинхронная отправка и ошибка сервера.** Если сервер вернул ошибку, её показывают либо общей плашкой, либо через `setError` у конкретного поля.

### **Ход работы:**

1. Создать новый React-проект (Vite + TypeScript).
2. Установить `react-hook-form`, `zod` и `@hookform/resolvers`.
3. Описать схему валидации согласно варианту в файле `src/schemas/`.
4. Создать компонент формы, подключить `useForm` с `zodResolver`.
5. Разметить поля через `register`, добавить видимые `label`.
6. Вывести ошибки под полями и настроить доступность (`aria-invalid`, `aria-describedby`).
7. Реализовать отправку формы с состоянием `isSubmitting` и уведомлением об успехе.
8. Проверить работу в браузере (`npm run dev`), отдельно проверить невалидные данные.
9. Оформить README.md с описанием работы.

2. **src/schemas/registrationSchema.ts:**
```ts
import { z } from 'zod';

export const registrationSchema = z
  .object({
    name: z
      .string()
      .min(2, 'Имя должно содержать минимум 2 символа')
      .max(50, 'Имя не должно превышать 50 символов')
      .regex(/^[А-Яа-яЁёA-Za-z\s-]+$/, 'Имя может содержать только буквы, пробел и дефис'),
    email: z.email('Введите корректный email'),
    password: z
      .string()
      .min(8, 'Пароль должен содержать минимум 8 символов')
      .regex(/[A-ZА-ЯЁ]/, 'Добавьте хотя бы одну заглавную букву')
      .regex(/[0-9]/, 'Добавьте хотя бы одну цифру'),
    confirmPassword: z.string().min(1, 'Подтвердите пароль'),
  })
  .refine((data) => data.password === data.confirmPassword, {
    error: 'Пароли не совпадают',
    path: ['confirmPassword'],
  });

export type RegistrationValues = z.infer<typeof registrationSchema>;
```

3. **src/components/RegistrationForm.tsx:**
```tsx
import { useState } from 'react';
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { registrationSchema } from '../schemas/registrationSchema';
import type { RegistrationValues } from '../schemas/registrationSchema';

interface FieldErrorProps {
  id: string;
  message?: string;
}

function FieldError({ id, message }: FieldErrorProps) {
  if (!message) {
    return null;
  }
  return (
    <span id={id} className="field-error" role="alert">
      {message}
    </span>
  );
}

export function RegistrationForm() {
  const [success, setSuccess] = useState(false);
  const [serverError, setServerError] = useState<string | null>(null);

  const {
    register,
    handleSubmit,
    reset,
    formState: { errors, isSubmitting },
  } = useForm<RegistrationValues>({
    resolver: zodResolver(registrationSchema),
    defaultValues: {
      name: '',
      email: '',
      password: '',
      confirmPassword: '',
    },
  });

  async function onSubmit(values: RegistrationValues) {
    setServerError(null);
    setSuccess(false);

    try {
      // Имитация запроса к серверу
      await new Promise((resolve) => setTimeout(resolve, 1500));
      console.log('Отправленные данные:', values);
      setSuccess(true);
      reset();
    } catch {
      setServerError('Не удалось отправить форму. Попробуйте ещё раз.');
    }
  }

  return (
    <form className="registration-form" onSubmit={handleSubmit(onSubmit)} noValidate>
      <h2>Регистрация</h2>

      <div className="field">
        <label htmlFor="name">Имя</label>
        <input
          id="name"
          type="text"
          placeholder="Иван Петров"
          aria-invalid={Boolean(errors.name)}
          aria-describedby={errors.name ? 'name-error' : undefined}
          {...register('name')}
        />
        <FieldError id="name-error" message={errors.name?.message} />
      </div>

      <div className="field">
        <label htmlFor="email">Email</label>
        <input
          id="email"
          type="email"
          placeholder="user@example.com"
          aria-invalid={Boolean(errors.email)}
          aria-describedby={errors.email ? 'email-error' : undefined}
          {...register('email')}
        />
        <FieldError id="email-error" message={errors.email?.message} />
      </div>

      <div className="field">
        <label htmlFor="password">Пароль</label>
        <input
          id="password"
          type="password"
          aria-invalid={Boolean(errors.password)}
          aria-describedby={errors.password ? 'password-error' : undefined}
          {...register('password')}
        />
        <FieldError id="password-error" message={errors.password?.message} />
      </div>

      <div className="field">
        <label htmlFor="confirmPassword">Подтверждение пароля</label>
        <input
          id="confirmPassword"
          type="password"
          aria-invalid={Boolean(errors.confirmPassword)}
          aria-describedby={errors.confirmPassword ? 'confirm-error' : undefined}
          {...register('confirmPassword')}
        />
        <FieldError id="confirm-error" message={errors.confirmPassword?.message} />
      </div>

      {serverError && (
        <p className="form-error" role="alert">
          {serverError}
        </p>
      )}

      {success && (
        <p className="form-success" role="status">
          Регистрация прошла успешно!
        </p>
      )}

      <button type="submit" disabled={isSubmitting}>
        {isSubmitting ? 'Отправка…' : 'Зарегистрироваться'}
      </button>
    </form>
  );
}
```

6. **Дополнение: форма обратной связи с выбором темы.** Показывает работу с `z.enum`, `z.boolean` и `watch`.
```tsx
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { z } from 'zod';

const feedbackSchema = z.object({
  topic: z.enum(['order', 'delivery', 'quality', 'other'], {
    error: 'Выберите тему обращения',
  }),
  message: z.string().min(10, 'Опишите проблему подробнее (минимум 10 символов)'),
  contact: z.email('Введите корректный email для ответа'),
  newsletter: z.boolean(),
});

type FeedbackValues = z.infer<typeof feedbackSchema>;

export function FeedbackForm() {
  const { register, handleSubmit, watch, formState } = useForm<FeedbackValues>({
    resolver: zodResolver(feedbackSchema),
    defaultValues: { topic: 'order', message: '', contact: '', newsletter: false },
  });

  const message = watch('message');

  return (
    <form onSubmit={handleSubmit((values) => console.log(values))} noValidate>
      <label htmlFor="topic">Тема обращения</label>
      <select id="topic" {...register('topic')}>
        <option value="order">Заказ</option>
        <option value="delivery">Доставка</option>
        <option value="quality">Качество</option>
        <option value="other">Другое</option>
      </select>

      <label htmlFor="message">Сообщение</label>
      <textarea id="message" {...register('message')} />
      <span className="field-error">{formState.errors.message?.message}</span>
      <small>Введено символов: {message.length}</small>

      <label htmlFor="contact">Email для ответа</label>
      <input id="contact" type="email" {...register('contact')} />
      <span className="field-error">{formState.errors.contact?.message}</span>

      <label>
        <input type="checkbox" {...register('newsletter')} />
        Подписаться на новости
      </label>

      <button type="submit">Отправить</button>
    </form>
  );
}
```

## **Инструкция по сдаче работы:**

1. Создать репозиторий на Gogs
2. Клонировать репозиторий локально
3. Создать React-проект в папке репозитория:
   ```bash
   npm create vite@latest . -- --template react-ts
   npm install
   npm install react-hook-form zod @hookform/resolvers
   ```
4. Реализовать форму и схему валидации согласно варианту
5. Сделать коммиты с понятными сообщениями
6. Добавить скриншоты работы в папку `assets/images`
7. Оформить README.md
8. Запушить изменения в Gogs
9. Предоставить ссылку на репозиторий преподавателю
