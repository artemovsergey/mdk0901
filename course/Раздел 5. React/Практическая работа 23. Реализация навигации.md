# Практическая работа 23. Реализация навигации

### **Тема:** Маршрутизация и навигация в React Router

### **Цель:**
Научиться настраивать маршрутизацию в React-приложениях с помощью React Router, создавать многостраничные SPA, использовать общий Layout, читать параметры маршрута, выполнять программную навигацию и защищать отдельные страницы от неавторизованного доступа.

### **Теоретическая часть:**

**React Router** — библиотека маршрутизации для React. В SPA-режиме она связывает адрес в браузере с компонентом, который нужно показать, без перезагрузки страницы.

**Основные понятия:**
- **Маршрут (route)** — правило «адрес → компонент»;
- **`createBrowserRouter`** — создаёт роутер из массива маршрутов (data router);
- **`RouterProvider`** — компонент, который подключает роутер к приложению;
- **`Outlet`** — место в родительском компоненте, куда вставляется дочерний маршрут;
- **`Link` / `NavLink`** — ссылки без перезагрузки; `NavLink` умеет подсвечивать активный маршрут;
- **`useParams`** — чтение параметров пути (`/catalog/:id`);
- **`useNavigate`** — программный переход;
- **`Navigate`** — декларативный редирект.

**Установка:**
```bash
npm install react-router
```

**Задание маршрутов:**
```tsx
import { createBrowserRouter, RouterProvider } from 'react-router';

const router = createBrowserRouter([
  {
    path: '/',
    element: <RootLayout />,
    children: [
      { index: true, element: <HomePage /> },
      { path: 'catalog', element: <CatalogPage /> },
      { path: 'catalog/:id', element: <ItemPage /> },
      { path: '*', element: <NotFoundPage /> },
    ],
  },
]);

export function App() {
  return <RouterProvider router={router} />;
}
```
Поле `index: true` обозначает маршрут по умолчанию для родительского пути. Маршрут `path: '*'` перехватывает все неизвестные адреса и показывает страницу 404.

**Общий Layout.** Компонент-обёртка с навигацией и `<Outlet />` — сюда подставляется содержимое дочернего маршрута:
```tsx
import { Link, NavLink, Outlet } from 'react-router';

export function RootLayout() {
  return (
    <div>
      <header>
        <Link to="/">Главная</Link>
        <NavLink to="/catalog" className={({ isActive }) => (isActive ? 'active' : '')}>
          Каталог
        </NavLink>
      </header>
      <main>
        <Outlet />
      </main>
    </div>
  );
}
```

**Активная ссылка.** У `NavLink` свойство `className` может быть функцией, которая получает `{ isActive, isPending }`. Так активный пункт меню получает отдельный класс.

**Параметры маршрута.** Маршрут `catalog/:id` объявляет динамический сегмент. Значение читается хуком `useParams`:
```tsx
const { id } = useParams<{ id: string }>();
```

**Программная навигация.** Хук `useNavigate` возвращает функцию перехода:
```tsx
const navigate = useNavigate();
navigate('/login');
navigate(-1); // назад
navigate('/login', { replace: true });
```

**Защищённый маршрут.** Компонент-обёртка проверяет авторизацию. Если пользователь не вошёл — он рендерит `<Navigate to="/login" replace />` и запоминает исходный адрес, чтобы вернуться после входа. В конфигурации маршрута защищённый компонент указывают как родителя с `children` и `<Outlet />`.

**Страница 404.** Маршрут `path: '*'` показывает компонент «Страница не найдена» с ссылкой на главную.

**Вложенность и `errorElement`.** В объект маршрута можно добавить `errorElement` — компонент, который показывается при ошибке загрузки данных маршрута.

4. **src/context/AuthContext.tsx (упрощённый контекст авторизации):**
```tsx
import { createContext, useCallback, useContext, useMemo, useState } from 'react';
import type { ReactNode } from 'react';

interface AuthContextValue {
  userName: string | null;
  isAuthenticated: boolean;
  login: (name: string) => void;
  logout: () => void;
}

const AuthContext = createContext<AuthContextValue | null>(null);

export function AuthProvider({ children }: { children: ReactNode }) {
  const [userName, setUserName] = useState<string | null>(null);

  const login = useCallback((name: string) => setUserName(name), []);
  const logout = useCallback(() => setUserName(null), []);

  const value = useMemo<AuthContextValue>(
    () => ({ userName, isAuthenticated: userName !== null, login, logout }),
    [userName, login, logout],
  );

  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>;
}

export function useAuth(): AuthContextValue {
  const context = useContext(AuthContext);
  if (!context) {
    throw new Error('useAuth должен использоваться внутри AuthProvider');
  }
  return context;
}
```

6. **src/components/ProtectedRoute.tsx:**
```tsx
import { Navigate, Outlet, useLocation } from 'react-router';
import { useAuth } from '../context/AuthContext';

/** Пропускает дальше только авторизованных, иначе перенаправляет на вход. */
export function ProtectedRoute() {
  const { isAuthenticated } = useAuth();
  const location = useLocation();

  if (!isAuthenticated) {
    // Запоминаем адрес, чтобы вернуться после входа
    return <Navigate to="/login" replace state={{ from: location.pathname }} />;
  }

  return <Outlet />;
}
```

```tsx
import { Link, useNavigate, useParams } from 'react-router';
import { items } from '../data/items';

export function ItemPage() {
  const { id } = useParams<{ id: string }>();
  const navigate = useNavigate();
  const item = items.find((current) => current.id === Number(id));

  if (!item) {
    return (
      <section className="page">
        <h1>Элемент не найден</h1>
        <Link to="/catalog">Вернуться в каталог</Link>
      </section>
    );
  }

  return (
    <section className="page">
      <h1>{item.title}</h1>
      <p>{item.description}</p>
      <p className="hint">Идентификатор маршрута: {id}</p>
      <button type="button" onClick={() => navigate(-1)}>
        Назад
      </button>
    </section>
  );
}
```

10. **src/pages/LoginPage.tsx (возврат на исходную страницу):**
```tsx
import { useState } from 'react';
import type { FormEvent } from 'react';
import { useLocation, useNavigate } from 'react-router';
import { useAuth } from '../context/AuthContext';

interface LocationState {
  from?: string;
}

export function LoginPage() {
  const { login } = useAuth();
  const navigate = useNavigate();
  const location = useLocation();
  const from = (location.state as LocationState | null)?.from ?? '/';

  const [name, setName] = useState('');

  function handleSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    if (!name.trim()) {
      return;
    }
    login(name.trim());
    navigate(from, { replace: true });
  }

  return (
    <section className="page">
      <h1>Вход</h1>
      <form className="login-form" onSubmit={handleSubmit}>
        <label htmlFor="userName">Имя пользователя</label>
        <input
          id="userName"
          type="text"
          value={name}
          onChange={(event) => setName(event.target.value)}
          placeholder="Введите имя"
        />
        <button type="submit">Войти</button>
      </form>
      <p className="hint">После входа вы вернётесь на страницу: {from}</p>
    </section>
  );
}
```

- Отсутствует защита маршрутов
- Код не соответствует требованиям
- README.md отсутствует или неинформативен
