# Самостоятельная работа 7. UI-библиотеки React: Mantine и Ant Design

### **Тема:** Создание современных пользовательских интерфейсов с помощью готовых UI-библиотек

### **Цель:**
Познакомиться с популярными UI-библиотеками React — Mantine и Ant Design. Освоить установку и подключение библиотеки, использование готовых компонентов (кнопки, поля ввода, таблицы, модальные окна, уведомления), настройку темы и локализации. Сравнить библиотеки между собой и с подходом shadcn/ui, а также применить одну из них в собственном приложении согласно варианту задания.

### **Теоретическая часть:**

**UI-библиотека** — это набор готовых компонентов и стилей, который ускоряет разработку интерфейса. Вместо того чтобы писать кнопку, поле ввода и таблицу с нуля, разработчик подключает библиотеку и настраивает внешний вид под проект.

Условно можно выделить два подхода к UI в React:
- **Компонентные библиотеки** (Mantine, Ant Design) — дают готовые компоненты со своим дизайном и набором props, тема настраивается через объект-конфиг.
- **Headless-подход** (shadcn/ui + Tailwind CSS) — копирует компоненты в проект, логика и доступность есть, а внешний вид полностью настраивает разработчик классами Tailwind.

---

#### **Mantine**

**Mantine** — современная библиотека с большим набором компонентов, хуков (`@mantine/hooks`) и утилит. Отличается строгим API, качественной типизацией, поддержкой тёмной темы «из коробки» и встроенной доступностью (a11y).

**Ключевые особенности:**
- Более 120 компонентов и 50+ хуков;
- настройка темы через объект `MantineProvider`;
- отдельные пакеты: `@mantine/core`, `@mantine/hooks`, `@mantine/form`, `@mantine/notifications`, `@mantine/modals`, `@mantine/dates`;
- TypeScript-first: все props типизированы;
- встроенная поддержка тёмной и светлой темы.

**Установка:**
```bash
npm install @mantine/core @mantine/hooks @mantine/form @mantine/notifications
```

**Подключение провайдера и стилей (src/main.tsx):**
```tsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import { MantineProvider } from '@mantine/core';
import { Notifications } from '@mantine/notifications';
import App from './App';

import '@mantine/core/styles.css';
import '@mantine/notifications/styles.css';
import './index.css';

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <MantineProvider defaultColorScheme="light" theme={{ primaryColor: 'blue' }}>
      <Notifications position="top-right" />
      <App />
    </MantineProvider>
  </StrictMode>,
);
```

**Типовые компоненты:** `Button`, `TextInput`, `Select`, `Checkbox`, `Card`, `Table`, `Modal`, `Badge`, `Group`, `Stack`, `Title`, `Text`, `ActionIcon`, `Loader`, `Alert`, `Tabs`.

---

#### **Ant Design**

**Ant Design** (antd) — зрелая корпоративная библиотека компонентов. Широко используется в административных панелях и дашбордах: богатые таблицы, формы, деревья, календари.

**Ключевые особенности:**
- Готовые компоненты для «тяжёлых» интерфейсов: `Table`, `Form`, `Tree`, `Transfer`, `DatePicker`;
- тема настраивается через `ConfigProvider` и дизайн-токены;
- встроенная локализация, в том числе русская (`antd/locale/ru_RU`);
- строгая система форм с правилами валидации в декларативном виде.

**Установка:**
```bash
npm install antd
```

**Подключение провайдера, темы и локализации (src/main.tsx):**
```tsx
import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';
import { ConfigProvider, App as AntApp } from 'antd';
import ruRU from 'antd/locale/ru_RU';
import App from './App';

import 'antd/dist/reset.css';
import './index.css';

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <ConfigProvider locale={ruRU} theme={{ token: { colorPrimary: '#1677ff', borderRadius: 8 } }}>
      <AntApp>
        <App />
      </AntApp>
    </ConfigProvider>
  </StrictMode>,
);
```

**Типовые компоненты:** `Button`, `Input`, `Select`, `Checkbox`, `Card`, `Table`, `Modal`, `Tag`, `Form`, `Space`, `Statistic`, `DatePicker`, `message`, `notification`.

#### **Сравнение библиотек**

| Критерий | Mantine | Ant Design | shadcn/ui + Tailwind |
|----------|---------|------------|----------------------|
| Подход | Готовая библиотека | Готовая библиотека | Копирование компонентов в проект |
| Компоненты | Широкий набор, акцент на UX | Богатый набор для админок | Базовый набор, растёт по мере надобности |
| Настройка темы | Объект `theme` в провайдере | Дизайн-токены в `ConfigProvider` | CSS-переменные и классы Tailwind |
| Стилизация | Props + CSS-модули | CSS-in-JS | Утилитарные классы |
| Локализация | Через `MantineProvider` и пропсы | Встроенная, есть `ru_RU` | Реализуется самостоятельно |
| Сложные таблицы/формы | Есть, но скромнее | Сильная сторона | Собираются из примитивов |
| Внешний вид из коробки | Современный, нейтральный | Корпоративный | Полностью свой |
| Размер бандла | Модульный, tree-shaking | Крупнее | Минимальный (только нужное) |

**Вывод.** Если нужен аккуратный современный интерфейс с большим числом компонентов и хуков — удобна Mantine. Если проект — админ-панель с таблицами, фильтрами и формами, — сильна Ant Design. Если важна полная свобода в дизайне и свой визуальный язык — уместен shadcn/ui + Tailwind.

### **Ход работы:**

1. Создать React-проект (Vite + TypeScript).
2. Установить выбранную библиотеку (Mantine или Ant Design).
3. Подключить провайдер и глобальные стили, при необходимости — локализацию.
4. Настроить тему (основной цвет, радиусы, тёмную/светлую схему).
5. Реализовать интерфейс согласно варианту задания из готовых компонентов.
6. Добавить интерактивность: формы, модальные окна, уведомления.
7. Обеспечить адаптивность (`Grid`, `SimpleGrid`, `Space` или CSS-медиазапросы).
8. Сравнить выбранную библиотеку с shadcn/ui в README.
9. Оформить README.md и подготовить отчёт.
10. Проверить работу в браузере (`npm run dev`).

3. **src/components/UsersPanel.tsx (форма, таблица, модальное окно, уведомления):**
```tsx
import { useState } from 'react';
import {
  ActionIcon,
  Badge,
  Button,
  Card,
  Group,
  Modal,
  Select,
  Table,
  Text,
  TextInput,
  Title,
} from '@mantine/core';
import { useForm } from '@mantine/form';
import { notifications } from '@mantine/notifications';

interface User {
  id: number;
  name: string;
  email: string;
  role: 'admin' | 'user';
  active: boolean;
}

const initialUsers: User[] = [
  { id: 1, name: 'Анна Иванова', email: 'anna@example.com', role: 'admin', active: true },
  { id: 2, name: 'Пётр Сидоров', email: 'petr@example.com', role: 'user', active: true },
  { id: 3, name: 'Мария Козлова', email: 'maria@example.com', role: 'user', active: false },
];

export function UsersPanel() {
  const [users, setUsers] = useState<User[]>(initialUsers);
  const [deleteId, setDeleteId] = useState<number | null>(null);

  const form = useForm({
    initialValues: { name: '', email: '', role: 'user' as User['role'] },
    validate: {
      name: (value) => (value.trim().length < 2 ? 'Введите имя (минимум 2 символа)' : null),
      email: (value) => (/^\S+@\S+\.\S+$/.test(value) ? null : 'Введите корректный email'),
    },
  });

  function handleSubmit(values: typeof form.values) {
    const newUser: User = {
      id: Math.max(0, ...users.map((user) => user.id)) + 1,
      name: values.name,
      email: values.email,
      role: values.role,
      active: true,
    };
    setUsers((prev) => [...prev, newUser]);
    form.reset();
    notifications.show({
      title: 'Готово',
      message: `Пользователь ${newUser.name} добавлен`,
      color: 'green',
    });
  }

  function confirmDelete() {
    if (deleteId === null) {
      return;
    }
    setUsers((prev) => prev.filter((user) => user.id !== deleteId));
    setDeleteId(null);
    notifications.show({
      title: 'Удалено',
      message: 'Пользователь удалён',
      color: 'red',
    });
  }

  return (
    <div className="panel">
      <Title order={1} mb="sm">
        Панель пользователей
      </Title>
      <Text c="dimmed" mb="lg">
        Пример интерфейса на компонентах Mantine.
      </Text>

      <Card withBorder radius="md" padding="lg" mb="xl">
        <Title order={3} mb="md">
          Добавить пользователя
        </Title>
        <form onSubmit={form.onSubmit(handleSubmit)}>
          <Group align="flex-end" grow>
            <TextInput label="Имя" placeholder="Иван Петров" {...form.getInputProps('name')} />
            <TextInput label="Email" placeholder="user@example.com" {...form.getInputProps('email')} />
            <Select
              label="Роль"
              data={[
                { value: 'user', label: 'Пользователь' },
                { value: 'admin', label: 'Администратор' },
              ]}
              {...form.getInputProps('role')}
            />
            <Button type="submit">Добавить</Button>
          </Group>
        </form>
      </Card>

      <Table striped highlightOnHover withTableBorder>
        <Table.Thead>
          <Table.Tr>
            <Table.Th>Имя</Table.Th>
            <Table.Th>Email</Table.Th>
            <Table.Th>Роль</Table.Th>
            <Table.Th>Статус</Table.Th>
            <Table.Th />
          </Table.Tr>
        </Table.Thead>
        <Table.Tbody>
          {users.map((user) => (
            <Table.Tr key={user.id}>
              <Table.Td>{user.name}</Table.Td>
              <Table.Td>{user.email}</Table.Td>
              <Table.Td>
                <Badge color={user.role === 'admin' ? 'blue' : 'gray'}>
                  {user.role === 'admin' ? 'Админ' : 'Пользователь'}
                </Badge>
              </Table.Td>
              <Table.Td>
                <Badge color={user.active ? 'green' : 'red'}>
                  {user.active ? 'Активен' : 'Отключён'}
                </Badge>
              </Table.Td>
              <Table.Td>
                <ActionIcon
                  color="red"
                  variant="subtle"
                  aria-label={`Удалить ${user.name}`}
                  onClick={() => setDeleteId(user.id)}
                >
                  ✕
                </ActionIcon>
              </Table.Td>
            </Table.Tr>
          ))}
        </Table.Tbody>
      </Table>

      <Modal opened={deleteId !== null} onClose={() => setDeleteId(null)} title="Удаление">
        <Text mb="lg">Удалить выбранного пользователя?</Text>
        <Group justify="flex-end">
          <Button variant="default" onClick={() => setDeleteId(null)}>
            Отмена
          </Button>
          <Button color="red" onClick={confirmDelete}>
            Удалить
          </Button>
        </Group>
      </Modal>
    </div>
  );
}
```

5. **Эквивалент на Ant Design (для сравнения).** Компоненты api: `Table`, `Form`, `Modal`, `message`, `Tag`.
```tsx
import { useState } from 'react';
import {
  Button,
  Card,
  Form,
  Input,
  Modal,
  Select,
  Space,
  Table,
  Tag,
  message,
} from 'antd';
import type { TableColumnsType } from 'antd';

interface User {
  key: number;
  name: string;
  email: string;
  role: 'admin' | 'user';
}

const initialUsers: User[] = [
  { key: 1, name: 'Анна Иванова', email: 'anna@example.com', role: 'admin' },
  { key: 2, name: 'Пётр Сидоров', email: 'petr@example.com', role: 'user' },
];

export function UsersTableAnt() {
  const [users, setUsers] = useState<User[]>(initialUsers);
  const [form] = Form.useForm();

  const columns: TableColumnsType<User> = [
    { title: 'Имя', dataIndex: 'name', key: 'name' },
    { title: 'Email', dataIndex: 'email', key: 'email' },
    {
      title: 'Роль',
      dataIndex: 'role',
      key: 'role',
      render: (role: User['role']) => (
        <Tag color={role === 'admin' ? 'blue' : 'default'}>
          {role === 'admin' ? 'Админ' : 'Пользователь'}
        </Tag>
      ),
    },
  ];

  function handleFinish(values: { name: string; email: string; role: User['role'] }) {
    setUsers((prev) => [...prev, { key: Date.now(), ...values }]);
    form.resetFields();
    message.success(`Пользователь ${values.name} добавлен`);
  }

  return (
    <Card title="Пользователи">
      <Form form={form} layout="inline" onFinish={handleFinish} style={{ marginBottom: 16 }}>
        <Form.Item name="name" rules={[{ required: true, message: 'Введите имя' }]}>
          <Input placeholder="Имя" />
        </Form.Item>
        <Form.Item
          name="email"
          rules={[
            { required: true, message: 'Введите email' },
            { type: 'email', message: 'Некорректный email' },
          ]}
        >
          <Input placeholder="Email" />
        </Form.Item>
        <Form.Item name="role" initialValue="user">
          <Select
            style={{ width: 160 }}
            options={[
              { value: 'user', label: 'Пользователь' },
              { value: 'admin', label: 'Администратор' },
            ]}
          />
        </Form.Item>
        <Form.Item>
          <Space>
            <Button type="primary" htmlType="submit">
              Добавить
            </Button>
          </Space>
        </Form.Item>
      </Form>

      <Table<User> columns={columns} dataSource={users} pagination={{ pageSize: 5 }} />
    </Card>
  );
}
```
