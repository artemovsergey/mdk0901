# Практическая работа. UI-компоненты на shadcn/ui и Tailwind

### **Тема:** Создание современных интерфейсов с помощью Tailwind CSS v4 и shadcn/ui

### **Цель:**
Научиться собирать интерфейсы React-приложений на утилитарном CSS (Tailwind CSS v4) и готовых UI-компонентах shadcn/ui. Освоить подключение Tailwind к Vite, работу с утилитарными классами и адаптивными префиксами, настройку темы через `@theme`, установку и использование компонентов shadcn/ui и утилиту `cn()`.

### **Теоретическая часть:**

**Tailwind CSS** — CSS-фреймворк, построенный на утилитарных классах. Вместо отдельного файла стилей под каждый компонент вы описываете оформление классами прямо в JSX: `flex`, `gap-4`, `rounded-lg`, `bg-blue-500`, `text-sm`.

**Преимущества Tailwind:**

*   нет «мёртвого» CSS и придумывания имён классов;
*   единые отступы, цвета и размеры из встроенной шкалы;
*   адаптивность через префиксы (`sm:`, `md:`, `lg:`);
*   стили не конфликтуют: итоговый CSS небольшой.

**Tailwind CSS v4** подключается к Vite как плагин — отдельный конфигурационный файл и PostCSS больше не нужны.

**shadcn/ui** — это не библиотека-зависимость, а **набор исходного кода компонентов**, который копируется в ваш проект командой. Компоненты построены на Radix UI (доступность из коробки), Tailwind CSS и class-variance-authority. Вы получаете файлы в `src/components/ui/` и можете свободно их редактировать под свой дизайн. Обновления библиотеки при этом не перезаписывают ваш код.

**Основные преимущества shadcn/ui:**

*   код компонентов принадлежит вам — можно менять как угодно;
*   встроенная доступность (клавиатура, ARIA, фокус);
*   согласованный дизайн через переменные темы;
*   варианты компонентов (`variant`, `size`) через CVA;
*   стили на Tailwind — легко переопределять.

**Ключевые компоненты, которые чаще всего используются:**

*   **Формы:** `Input`, `Textarea`, `Select`, `Checkbox`, `Switch`, `Slider`;
*   **Отображение:** `Card`, `Badge`, `Avatar`, `Table`, `Separator`, `Tabs`;
*   **Обратная связь:** `Dialog`, `AlertDialog`, `Toast` (Sonner), `Progress`, `Skeleton`;
*   **Кнопки:** `Button` с вариантами `default`, `secondary`, `outline`, `ghost`, `destructive`.

### **Установка и настройка:**

1. **Создание проекта и установка Tailwind CSS v4:**

```bash
npm create vite@latest ui-practice -- --template react-ts
cd ui-practice
npm install
npm install tailwindcss @tailwindcss/vite
```

2. **Подключение плагина Tailwind в `vite.config.ts`:**

```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
})
```

3. **Импорт Tailwind в `src/index.css`** (содержимое демо-стилей шаблона можно удалить):

```css
@import "tailwindcss";
```

4. **Настройка алиаса `@/`** (нужен для shadcn/ui). В `tsconfig.app.json`:

```jsonc
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

В `vite.config.ts` добавьте разрешение алиаса:

```typescript
import path from 'node:path'
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
})
```

Для `path` и `__dirname` установите типы Node: `npm install -D @types/node`.

5. **Инициализация shadcn/ui:**

```bash
npx shadcn@latest init
```

Утилита спросит базовый цвет темы и создаст:

*   `components.json` — конфигурация shadcn;
*   `src/lib/utils.ts` — утилита `cn()`;
*   переменные темы в `src/index.css`.

6. **Добавление компонентов:**

```bash
npx shadcn@latest add button card input dialog table badge avatar
```

Компоненты появятся в `src/components/ui/`. Это обычные TSX-файлы — их можно открыть и изменить.

### **Ход работы:**

1. Создать новый React-проект (Vite + TypeScript)
2. Установить и подключить Tailwind CSS v4
3. Инициализировать shadcn/ui и добавить нужные компоненты
4. Реализовать интерфейс согласно варианту задания в папке `src/components/`
5. Организовать адаптивную вёрстку (префиксы `sm:`, `md:`, `lg:`)
6. Проверить доступность: фокус с клавиатуры, подписи у полей, контраст
7. Проверить работу в браузере (`npm run dev`) и собрать проект (`npm run build`)
8. Оформить README.md с описанием работы

### **Практический пример:**

**Страница профиля студента с `Card`, `Button`, `Input`, `Avatar` и адаптивной сеткой.**

1. **Утилита `cn()`** (создаётся при `init`, но полезно понимать её устройство):

```typescript
// src/lib/utils.ts
import { clsx, type ClassValue } from 'clsx'
import { twMerge } from 'tailwind-merge'

// clsx собирает классы по условию, twMerge убирает конфликты Tailwind
export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

2. **Утилитарные классы и тема.** В `src/index.css` опишем фирменные цвета и радиусы:

```css
@import "tailwindcss";

/* Кастомная тема: переменные с префиксом --color-* становятся классами */
@theme {
  --color-brand-50: #eff6ff;
  --color-brand-500: #3b82f6;
  --color-brand-600: #2563eb;
  --radius-card: 0.75rem;
}

/* Базовые стили страницы */
body {
  @apply bg-slate-50 text-slate-900 antialiased;
}
```

После этого доступны классы `bg-brand-500`, `text-brand-600`, `rounded-card`.

5. **Диалог подтверждения действия.** Компонент `Dialog` из shadcn/ui автоматически управляет фокусом и закрытием по Escape:

```tsx
// src/components/DeleteAccountDialog.tsx
import { Button } from '@/components/ui/button'
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from '@/components/ui/dialog'

export function DeleteAccountDialog({ onConfirm }: { onConfirm: () => void }) {
  return (
    <Dialog>
      <DialogTrigger asChild>
        <Button variant="destructive">Удалить аккаунт</Button>
      </DialogTrigger>

      <DialogContent>
        <DialogHeader>
          <DialogTitle>Удалить аккаунт?</DialogTitle>
          <DialogDescription>
            Действие необратимо: все данные будут удалены безвозвратно.
          </DialogDescription>
        </DialogHeader>

        <DialogFooter>
          <Button variant="outline">Отмена</Button>
          <Button variant="destructive" onClick={onConfirm}>
            Удалить
          </Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  )
}
```

## **Пример реализации для Варианта 1 (Управление пользователями):**

```tsx
// src/pages/UserManagementPage.tsx
import { useMemo, useState } from 'react'
import { Badge } from '@/components/ui/badge'
import { Button } from '@/components/ui/button'
import {
  Card,
  CardContent,
  CardHeader,
  CardTitle,
} from '@/components/ui/card'
import {
  Dialog,
  DialogContent,
  DialogFooter,
  DialogHeader,
  DialogTitle,
} from '@/components/ui/dialog'
import { Input } from '@/components/ui/input'
import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from '@/components/ui/table'

type Role = 'admin' | 'moderator' | 'user'
type Status = 'active' | 'inactive'

interface User {
  id: number
  name: string
  email: string
  role: Role
  status: Status
}

const initialUsers: User[] = [
  { id: 1, name: 'Анна Иванова', email: 'anna@example.com', role: 'admin', status: 'active' },
  { id: 2, name: 'Пётр Сидоров', email: 'petr@example.com', role: 'user', status: 'active' },
  { id: 3, name: 'Мария Козлова', email: 'maria@example.com', role: 'moderator', status: 'inactive' },
]

const roleLabels: Record<Role, string> = {
  admin: 'Администратор',
  moderator: 'Модератор',
  user: 'Пользователь',
}

export function UserManagementPage() {
  const [users, setUsers] = useState<User[]>(initialUsers)
  const [search, setSearch] = useState('')
  const [roleFilter, setRoleFilter] = useState<Role | 'all'>('all')
  const [isDialogOpen, setIsDialogOpen] = useState(false)
  const [draft, setDraft] = useState<Omit<User, 'id'>>({
    name: '',
    email: '',
    role: 'user',
    status: 'active',
  })

  const filtered = useMemo(() => {
    const query = search.trim().toLowerCase()
    return users.filter((user) => {
      const matchesQuery =
        !query ||
        user.name.toLowerCase().includes(query) ||
        user.email.toLowerCase().includes(query)
      const matchesRole = roleFilter === 'all' || user.role === roleFilter
      return matchesQuery && matchesRole
    })
  }, [users, search, roleFilter])

  const handleCreate = () => {
    if (!draft.name || !draft.email) return
    const nextId = Math.max(0, ...users.map((u) => u.id)) + 1
    setUsers((prev) => [...prev, { ...draft, id: nextId }])
    setDraft({ name: '', email: '', role: 'user', status: 'active' })
    setIsDialogOpen(false)
  }

  const handleDelete = (id: number) => {
    setUsers((prev) => prev.filter((user) => user.id !== id))
  }

  return (
    <div className="mx-auto max-w-6xl space-y-6 px-4 py-8 sm:px-6 lg:px-8">
      <div className="flex flex-col gap-4 sm:flex-row sm:items-center sm:justify-between">
        <h1 className="text-2xl font-semibold tracking-tight">
          Управление пользователями
        </h1>
        <Button onClick={() => setIsDialogOpen(true)}>
          Добавить пользователя
        </Button>
      </div>

      <Card>
        <CardHeader>
          <CardTitle className="text-base">Фильтры</CardTitle>
        </CardHeader>
        <CardContent className="grid gap-4 sm:grid-cols-2">
          <div className="space-y-2">
            <label htmlFor="user-search" className="text-sm font-medium">
              Поиск
            </label>
            <Input
              id="user-search"
              placeholder="Имя или email"
              value={search}
              onChange={(e) => setSearch(e.target.value)}
            />
          </div>

          <div className="space-y-2">
            <label htmlFor="role-filter" className="text-sm font-medium">
              Роль
            </label>
            <select
              id="role-filter"
              className="h-9 w-full rounded-md border border-input bg-transparent px-3 text-sm shadow-sm outline-none focus-visible:ring-2 focus-visible:ring-ring"
              value={roleFilter}
              onChange={(e) => setRoleFilter(e.target.value as Role | 'all')}
            >
              <option value="all">Все роли</option>
              <option value="admin">Администратор</option>
              <option value="moderator">Модератор</option>
              <option value="user">Пользователь</option>
            </select>
          </div>
        </CardContent>
      </Card>

      <Card>
        <CardContent className="p-0">
          <div className="overflow-x-auto">
            <Table>
              <TableHeader>
                <TableRow>
                  <TableHead>Имя</TableHead>
                  <TableHead>Email</TableHead>
                  <TableHead>Роль</TableHead>
                  <TableHead>Статус</TableHead>
                  <TableHead className="text-right">Действия</TableHead>
                </TableRow>
              </TableHeader>
              <TableBody>
                {filtered.length === 0 ? (
                  <TableRow>
                    <TableCell colSpan={5} className="py-8 text-center text-muted-foreground">
                      Пользователи не найдены
                    </TableCell>
                  </TableRow>
                ) : (
                  filtered.map((user) => (
                    <TableRow key={user.id}>
                      <TableCell className="font-medium">{user.name}</TableCell>
                      <TableCell>{user.email}</TableCell>
                      <TableCell>
                        <Badge variant="outline">{roleLabels[user.role]}</Badge>
                      </TableCell>
                      <TableCell>
                        <Badge variant={user.status === 'active' ? 'default' : 'secondary'}>
                          {user.status === 'active' ? 'Активен' : 'Неактивен'}
                        </Badge>
                      </TableCell>
                      <TableCell className="text-right">
                        <Button
                          variant="ghost"
                          size="sm"
                          onClick={() => handleDelete(user.id)}
                        >
                          Удалить
                        </Button>
                      </TableCell>
                    </TableRow>
                  ))
                )}
              </TableBody>
            </Table>
          </div>
        </CardContent>
      </Card>

      <Dialog open={isDialogOpen} onOpenChange={setIsDialogOpen}>
        <DialogContent>
          <DialogHeader>
            <DialogTitle>Новый пользователь</DialogTitle>
          </DialogHeader>

          <div className="space-y-4">
            <div className="space-y-2">
              <label htmlFor="new-name" className="text-sm font-medium">
                Имя
              </label>
              <Input
                id="new-name"
                value={draft.name}
                onChange={(e) => setDraft({ ...draft, name: e.target.value })}
              />
            </div>

            <div className="space-y-2">
              <label htmlFor="new-email" className="text-sm font-medium">
                Email
              </label>
              <Input
                id="new-email"
                type="email"
                value={draft.email}
                onChange={(e) => setDraft({ ...draft, email: e.target.value })}
              />
            </div>
          </div>

          <DialogFooter>
            <Button variant="outline" onClick={() => setIsDialogOpen(false)}>
              Отмена
            </Button>
            <Button onClick={handleCreate}>Добавить</Button>
          </DialogFooter>
        </DialogContent>
      </Dialog>
    </div>
  )
}
```
