# Практическая работа 20. Создание пользовательского хука

### **Тема:** Кастомные хуки React — переиспользование логики между компонентами

### **Цель:**
Научиться создавать собственные хуки в React, выносить повторяющуюся логику в отдельные функции и переиспользовать её в разных компонентах. Освоить правила хуков (Rules of Hooks), типизацию кастомных хуков с помощью дженериков TypeScript, а также применение хуков для работы с состоянием, побочными эффектами и внешними API.

### **Теоретическая часть:**

**Кастомный хук** — это обычная функция, имя которой начинается с `use`, и которая внутри вызывает другие хуки React (`useState`, `useEffect`, `useRef`, `useMemo` и т. д.). Такой хук позволяет вынести логику из компонента и использовать её повторно.

Зачем нужны кастомные хуки:
- **Переиспользование логики** — один и тот же код (загрузка данных, работа с localStorage, debounce) не дублируется в компонентах.
- **Читаемость** — компонент описывает, *что* он делает, а не *как* устроена техническая часть.
- **Тестируемость** — логику можно проверить отдельно от разметки.
- **Инкапсуляция** — детали реализации скрыты за понятным интерфейсом хука.

**Правила хуков (Rules of Hooks):**
1. Вызывать хуки можно только **на верхнем уровне** компонента или другого хука. Нельзя вызывать их внутри условий, циклов, вложенных функций.
2. Вызывать хуки можно только из **React-компонентов** или **других хуков**, но не из обычных функций.
3. Имя кастомного хука **обязательно начинается с `use`** — так линтер (`eslint-plugin-react-hooks`) понимает, что внутри есть хуки, и проверяет правила.

**Функция vs хук.** Обычная функция без хуков внутри — это просто утилита. Как только внутри появляются `useState`/`useEffect`, функция становится хуком и должна называться `useSomething`.

**Минимальный кастомный хук:**
```tsx
import { useState } from 'react';

export function useToggle(initial = false) {
  const [value, setValue] = useState(initial);
  const toggle = () => setValue((prev) => !prev);
  return { value, toggle };
}
```

**Типизация через дженерик.** Хук, который работает с разными типами данных, описывают с помощью параметра-типа `<T>`:
```tsx
import { useState } from 'react';

export function useLocalStorage<T>(key: string, initialValue: T) {
  const [value, setValue] = useState<T>(initialValue);
  // ...
  return [value, setValue] as const;
}
```
Атрибут `as const` нужен, чтобы TypeScript вывел кортеж `[T, Dispatch<SetStateAction<T>>]`, а не массив `(T | Dispatch<...>)[]`.

**Хук `useFetch` — загрузка данных.** Содержит три состояния: `data`, `loading`, `error`. Для отмены запроса при размонтировании компонента используют `AbortController`. Эффект запускается при изменении `url` — зависимость указывается в массиве `useEffect`.

**Хук `useDebounce` — отложенное значение.** Возвращает значение, которое обновляется только после паузы. Применяется для поиска по мере ввода, чтобы не отправлять запрос на каждую букву.

**Правила именования файлов.** Файл хука называют так же, как сам хук: `useFetch.ts`, `useLocalStorage.ts`. Хуки хранят в каталоге `src/hooks/`. Компоненты — в `src/components/`.

**Возвращаемое значение.** Хук обычно возвращает объект (`{ data, loading, error }`) — так у значений есть имена. Кортеж (`[value, setValue]`) уместен там, где хук повторяет интерфейс `useState`.

2. **src/hooks/useFetch.ts:**
```tsx
import { useCallback, useEffect, useState } from 'react';

interface UseFetchResult<T> {
  data: T | null;
  loading: boolean;
  error: string | null;
  refetch: () => void;
}

/**
 * Универсальный хук для загрузки данных по URL.
 * Возвращает данные, состояние загрузки, текст ошибки и функцию повторной загрузки.
 */
export function useFetch<T>(url: string): UseFetchResult<T> {
  const [data, setData] = useState<T | null>(null);
  const [loading, setLoading] = useState<boolean>(true);
  const [error, setError] = useState<string | null>(null);
  // Счётчик увеличивается при вызове refetch — это перезапускает эффект
  const [reloadKey, setReloadKey] = useState(0);

  useEffect(() => {
    const controller = new AbortController();

    async function load() {
      setLoading(true);
      setError(null);

      try {
        const response = await fetch(url, { signal: controller.signal });

        if (!response.ok) {
          throw new Error(`Ошибка запроса: ${response.status} ${response.statusText}`);
        }

        const result = (await response.json()) as T;
        setData(result);
      } catch (err) {
        // Отмена запроса — это не ошибка, не показываем её пользователю
        if (err instanceof DOMException && err.name === 'AbortError') {
          return;
        }
        setError(err instanceof Error ? err.message : 'Не удалось загрузить данные');
      } finally {
        if (!controller.signal.aborted) {
          setLoading(false);
        }
      }
    }

    void load();

    // Отменяем запрос при размонтировании или смене URL
    return () => controller.abort();
  }, [url, reloadKey]);

  const refetch = useCallback(() => setReloadKey((key) => key + 1), []);

  return { data, loading, error, refetch };
}
```

4. **src/hooks/useDebounce.ts (хук отложенного значения):**
```tsx
import { useEffect, useState } from 'react';

/**
 * Возвращает значение, которое обновляется только после паузы `delay` миллисекунд.
 */
export function useDebounce<T>(value: T, delay = 500): T {
  const [debouncedValue, setDebouncedValue] = useState<T>(value);

  useEffect(() => {
    const timeoutId = window.setTimeout(() => {
      setDebouncedValue(value);
    }, delay);

    return () => window.clearTimeout(timeoutId);
  }, [value, delay]);

  return debouncedValue;
}
```

5. **src/components/UserList.tsx (применение хука в компоненте):**
```tsx
import { useMemo, useState } from 'react';
import { useFetch } from '../hooks/useFetch';
import { useDebounce } from '../hooks/useDebounce';
import type { User } from '../types';

export function UserList() {
  const [search, setSearch] = useState('');
  const debouncedSearch = useDebounce(search, 400);

  const { data, loading, error, refetch } = useFetch<User[]>(
    'https://jsonplaceholder.typicode.com/users',
  );

  const filteredUsers = useMemo(() => {
    if (!data) {
      return [];
    }
    const query = debouncedSearch.trim().toLowerCase();
    if (!query) {
      return data;
    }
    return data.filter((user) => user.name.toLowerCase().includes(query));
  }, [data, debouncedSearch]);

  if (loading) {
    return <p className="state state-loading">Загрузка пользователей…</p>;
  }

  if (error) {
    return (
      <div className="state state-error" role="alert">
        <p>{error}</p>
        <button type="button" onClick={refetch}>
          Повторить
        </button>
      </div>
    );
  }

  return (
    <section className="user-list">
      <label className="search-field">
        <span>Поиск по имени</span>
        <input
          type="search"
          value={search}
          onChange={(event) => setSearch(event.target.value)}
          placeholder="Введите имя"
        />
      </label>

      {filteredUsers.length === 0 ? (
        <p className="state">Пользователи не найдены</p>
      ) : (
        <ul className="user-grid">
          {filteredUsers.map((user) => (
            <li key={user.id} className="user-card">
              <h3>{user.name}</h3>
              <p>{user.email}</p>
              <p className="user-company">{user.company.name}</p>
            </li>
          ))}
        </ul>
      )}
    </section>
  );
}
```

8. **Дополнение: хук `useLocalStorage`.** Тот же приём с дженериком позволяет хранить в браузере любой сериализуемый тип.
```tsx
import { useEffect, useState } from 'react';

export function useLocalStorage<T>(key: string, initialValue: T) {
  const [value, setValue] = useState<T>(() => {
    try {
      const stored = window.localStorage.getItem(key);
      return stored ? (JSON.parse(stored) as T) : initialValue;
    } catch {
      return initialValue;
    }
  });

  useEffect(() => {
    window.localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);

  return [value, setValue] as const;
}
```

import { useMemo, useState } from 'react';

export function useEmailValidation(initial = '') {
  const [email, setEmail] = useState(initial);

  const isValid = useMemo(
    () => /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email),
    [email],
  );

  return { email, setEmail, isValid };
}
```

      <input
        type="email"
        value={email}
        onChange={(event) => setEmail(event.target.value)}
        placeholder="user@example.com"
      />
      {email && !isValid && (
        <small className="error">Введите корректный email</small>
      )}
    </label>
  );
}
```
