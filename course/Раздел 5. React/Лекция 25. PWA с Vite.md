# Практическая работа. Создание PWA на Vite

### **Тема:** Progressive Web Apps — современные веб-приложения с нативным опытом

### **Цель:**
Научиться превращать React-приложение на Vite в Progressive Web App: настраивать web app manifest и service worker с помощью `vite-plugin-pwa`, обеспечивать офлайн-режим, устанавливать приложение на устройство и проверять результат в DevTools.

### **Теоретическая часть:**

**PWA (Progressive Web App)** — веб-приложение, которое использует современные возможности браузера, чтобы дать пользователю опыт, близкий к нативному приложению. PWA может работать без интернета, устанавливаться на домашний экран и обновляться автоматически.

**Ключевые характеристики PWA:**

*   **Надёжность** — приложение открывается и работает при отсутствии сети;
*   **Скорость** — статика кэшируется и загружается мгновенно;
*   **Устанавливаемость** — добавляется на устройство как обычное приложение;
*   **Вовлечённость** — полноэкранный режим, push-уведомления.

**Основные компоненты PWA:**

1.  **Web App Manifest** — JSON-файл с метаданными: название, иконки, цвета, режим отображения. Именно он делает приложение устанавливаемым.
2.  **Service Worker** — фоновый скрипт между приложением и сетью. Перехватывает запросы и отдаёт их из кэша, когда сети нет.
3.  **HTTPS** — обязательное условие (кроме `localhost`): service worker имеет доступ к сетевым запросам, поэтому требует защищённого соединения.
4.  **Адаптивный дизайн** — интерфейс должен корректно работать на любом экране.

**`vite-plugin-pwa`** — плагин, который автоматически генерирует manifest и service worker для production-сборки Vite. По умолчанию используется стратегия Workbox `generateSW`: плагин собирает service worker, кэширующий всю статику проекта.

Плагин умеет:

*   генерировать `manifest.webmanifest` из настроек в `vite.config.ts`;
*   кэшировать статические ресурсы (precache);
*   настраивать правила кэширования внешних запросов (`runtimeCaching`);
*   обновлять приложение при выходе новой версии (`registerType`);
*   регистрировать service worker автоматически или через виртуальный модуль `virtual:pwa-register`.

**Ограничения и подводные камни:**

*   service worker регистрируется только в **production-сборке** (`npm run build` + `npm run preview`), в dev-режиме его нужно включать отдельно (`devOptions.enabled: true`);
*   PWA требует HTTPS (кроме `localhost`), иначе браузер откажется регистрировать service worker;
*   кэш может «залипнуть»: после обновления версии иногда помогает жёсткая перезагрузка (Ctrl+Shift+R) или очистка Storage в DevTools;
*   не стоит кэшировать POST/PUT/DELETE-запросы и персональные данные — это приведёт к устаревшим ответам и проблемам безопасности;
*   обновление вступает в силу при следующей загрузке приложения (при `registerType: 'autoUpdate'`);
*   в iOS Safari установка и офлайн-режим имеют особенности — проверяйте на реальных устройствах.

### **Ход работы:**

1. Создать React-проект (Vite + TypeScript)
2. Установить `vite-plugin-pwa` и настроить плагин
3. Задать manifest: имя, короткое имя, цвета, иконки
4. Подготовить иконки 192×192 и 512×512
5. Реализовать приложение с локальным хранением данных
6. Собрать проект (`npm run build`) и проверить через `npm run preview`
7. Проверить Manifest и Service Worker в DevTools, протестировать офлайн
8. Оформить README.md с описанием работы

### **Практический пример:**

**Трекер привычек с офлайн-режимом.** Данные хранятся в `localStorage` через Zustand `persist`, поэтому приложение работает без сети.

1. **Установка плагина:**

```bash
npm create vite@latest habit-tracker-pwa -- --template react-ts
cd habit-tracker-pwa
npm install
npm install -D vite-plugin-pwa
npm install zustand
```

2. **Настройка `vite.config.ts`:**

```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import { VitePWA } from 'vite-plugin-pwa'

export default defineConfig({
  plugins: [
    react(),
    VitePWA({
      // Новая версия активируется автоматически
      registerType: 'autoUpdate',

      // Файлы из public, которые нужно добавить в precache
      includeAssets: ['favicon.ico', 'apple-touch-icon.png'],

      manifest: {
        name: 'Трекер привычек',
        short_name: 'HabitTracker',
        description: 'Приложение для отслеживания ежедневных привычек',
        theme_color: '#667eea',
        background_color: '#ffffff',
        display: 'standalone',
        scope: '/',
        start_url: '/',
        lang: 'ru-RU',
        icons: [
          {
            src: 'pwa-192x192.png',
            sizes: '192x192',
            type: 'image/png',
          },
          {
            src: 'pwa-512x512.png',
            sizes: '512x512',
            type: 'image/png',
          },
          {
            src: 'pwa-512x512.png',
            sizes: '512x512',
            type: 'image/png',
            purpose: 'any maskable',
          },
        ],
      },

      workbox: {
        // Что кэшировать в первую очередь (precache)
        globPatterns: ['**/*.{js,css,html,ico,png,svg,woff2}'],

        // Правила для внешних ресурсов
        runtimeCaching: [
          {
            urlPattern: /^https:\/\/fonts\.googleapis\.com\/.*/i,
            handler: 'CacheFirst',
            options: {
              cacheName: 'google-fonts-cache',
              expiration: { maxEntries: 10, maxAgeSeconds: 60 * 60 * 24 * 365 },
              cacheableResponse: { statuses: [0, 200] },
            },
          },
          {
            urlPattern: /\/api\/.*/i,
            handler: 'NetworkFirst',
            options: {
              cacheName: 'api-cache',
              networkTimeoutSeconds: 5,
              expiration: { maxEntries: 50, maxAgeSeconds: 60 * 60 * 24 },
            },
          },
        ],
      },

      // Включает service worker в dev-режиме для отладки
      devOptions: { enabled: true },
    }),
  ],
})
```

3. **Иконки.** Положите в папку `public/` два PNG-файла: `pwa-192x192.png` и `pwa-512x512.png`. Их можно сгенерировать на сайте `realfavicongenerator.net` или нарисовать в редакторе. Для «маскируемой» иконки (`maskable`) оставляйте важный элемент в центральной части — края могут обрезаться на разных платформах.

5. **Регистрация service worker в `src/main.tsx`:**

```tsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { registerSW } from 'virtual:pwa-register'
import App from './App'
import './index.css'

// Регистрируем service worker. При autoUpdate новая версия применяется сама
registerSW({ immediate: true })

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <App />
  </StrictMode>,
)
```

6. **Хранилище привычек на Zustand с `persist`** (данные переживают офлайн и перезагрузку):

```typescript
// src/store/habitsStore.ts
import { create } from 'zustand'
import { persist } from 'zustand/middleware'

export type Frequency = 'daily' | 'weekly' | 'monthly'

export interface Habit {
  id: string
  title: string
  description: string
  icon: string
  color: string
  frequency: Frequency
  completedDates: string[] // даты в формате YYYY-MM-DD
  createdAt: string
}

interface HabitsState {
  habits: Habit[]
  addHabit: (input: Omit<Habit, 'id' | 'createdAt' | 'completedDates'>) => void
  removeHabit: (id: string) => void
  toggleToday: (id: string) => void
}

export const todayKey = () => new Date().toISOString().slice(0, 10)

export const useHabitsStore = create<HabitsState>()(
  persist(
    (set) => ({
      habits: [],

      addHabit: (input) =>
        set((state) => ({
          habits: [
            ...state.habits,
            {
              ...input,
              id: crypto.randomUUID(),
              createdAt: new Date().toISOString(),
              completedDates: [],
            },
          ],
        })),

      removeHabit: (id) =>
        set((state) => ({
          habits: state.habits.filter((habit) => habit.id !== id),
        })),

      toggleToday: (id) =>
        set((state) => {
          const today = todayKey()
          return {
            habits: state.habits.map((habit) => {
              if (habit.id !== id) return habit

              const isDone = habit.completedDates.includes(today)
              return {
                ...habit,
                completedDates: isDone
                  ? habit.completedDates.filter((date) => date !== today)
                  : [...habit.completedDates, today],
              }
            }),
          }
        }),
    }),
    { name: 'habits-storage' },
  ),
)

// Селектор: процент выполнения за сегодня
export function completionRate(habits: Habit[]): number {
  if (habits.length === 0) return 0
  const today = todayKey()
  const done = habits.filter((habit) => habit.completedDates.includes(today)).length
  return Math.round((done / habits.length) * 100)
}

// Селектор: серия дней подряд
export function currentStreak(habits: Habit[]): number {
  if (habits.length === 0) return 0
  let streak = 0

  for (let i = 0; i < 30; i++) {
    const date = new Date()
    date.setDate(date.getDate() - i)
    const key = date.toISOString().slice(0, 10)
    const anyDone = habits.some((habit) => habit.completedDates.includes(key))
    if (!anyDone) break
    streak++
  }

  return streak
}
```

7. **Хук отслеживания статуса сети:**

```typescript
// src/hooks/useOnlineStatus.ts
import { useEffect, useState } from 'react'

export function useOnlineStatus(): boolean {
  const [isOnline, setIsOnline] = useState(() => navigator.onLine)

  useEffect(() => {
    const goOnline = () => setIsOnline(true)
    const goOffline = () => setIsOnline(false)

    window.addEventListener('online', goOnline)
    window.addEventListener('offline', goOffline)

    return () => {
      window.removeEventListener('online', goOnline)
      window.removeEventListener('offline', goOffline)
    }
  }, [])

  return isOnline
}
```

8. **Основной компонент:**

```tsx
// src/components/HabitTracker.tsx
import { useState } from 'react'
import type { FormEvent } from 'react'
import {
  completionRate,
  currentStreak,
  todayKey,
  useHabitsStore,
} from '../store/habitsStore'
import { useOnlineStatus } from '../hooks/useOnlineStatus'

const ICONS = ['💪', '📚', '💧', '🧘', '🎯', '🌱']

export function HabitTracker() {
  const habits = useHabitsStore((state) => state.habits)
  const addHabit = useHabitsStore((state) => state.addHabit)
  const removeHabit = useHabitsStore((state) => state.removeHabit)
  const toggleToday = useHabitsStore((state) => state.toggleToday)

  const isOnline = useOnlineStatus()
  const today = todayKey()

  const [title, setTitle] = useState('')
  const [icon, setIcon] = useState(ICONS[0])

  const handleAdd = (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault()
    if (!title.trim()) return

    addHabit({
      title: title.trim(),
      description: '',
      icon,
      color: '#667eea',
      frequency: 'daily',
    })
    setTitle('')
  }

  return (
    <div className="mx-auto max-w-2xl px-4 py-8">
      <header className="mb-6">
        <div className="flex items-center justify-between">
          <h1 className="text-2xl font-semibold">🎯 Трекер привычек</h1>
          <span
            className={
              isOnline
                ? 'rounded-full bg-green-100 px-3 py-1 text-sm text-green-700'
                : 'rounded-full bg-red-100 px-3 py-1 text-sm text-red-700'
            }
          >
            {isOnline ? 'Онлайн' : 'Офлайн'}
          </span>
        </div>

        {!isOnline ? (
          <p role="status" className="mt-3 rounded-md bg-amber-100 px-4 py-2 text-sm text-amber-800">
            Вы в офлайн-режиме. Изменения сохранены локально и не потеряются.
          </p>
        ) : null}
      </header>

      <section className="mb-6 grid grid-cols-3 gap-3">
        <div className="rounded-lg bg-indigo-600 p-4 text-center text-white">
          <div className="text-2xl font-bold">{habits.length}</div>
          <div className="text-sm opacity-90">Всего привычек</div>
        </div>
        <div className="rounded-lg bg-indigo-600 p-4 text-center text-white">
          <div className="text-2xl font-bold">{completionRate(habits)}%</div>
          <div className="text-sm opacity-90">Сегодня выполнено</div>
        </div>
        <div className="rounded-lg bg-indigo-600 p-4 text-center text-white">
          <div className="text-2xl font-bold">{currentStreak(habits)}</div>
          <div className="text-sm opacity-90">Дней подряд</div>
        </div>
      </section>

      <form onSubmit={handleAdd} className="mb-6 flex flex-col gap-3 sm:flex-row">
        <label htmlFor="habit-title" className="sr-only">
          Название привычки
        </label>
        <input
          id="habit-title"
          value={title}
          onChange={(e) => setTitle(e.target.value)}
          placeholder="Новая привычка…"
          className="flex-1 rounded-lg border border-slate-300 px-4 py-2 outline-none focus-visible:ring-2 focus-visible:ring-indigo-500"
        />

        <label htmlFor="habit-icon" className="sr-only">
          Иконка
        </label>
        <select
          id="habit-icon"
          value={icon}
          onChange={(e) => setIcon(e.target.value)}
          className="rounded-lg border border-slate-300 px-3 py-2"
        >
          {ICONS.map((value) => (
            <option key={value} value={value}>
              {value}
            </option>
          ))}
        </select>

        <button
          type="submit"
          disabled={!title.trim()}
          className="rounded-lg bg-indigo-600 px-5 py-2 font-medium text-white disabled:bg-slate-300"
        >
          Добавить
        </button>
      </form>

      {habits.length === 0 ? (
        <div className="rounded-lg bg-white p-10 text-center text-slate-500 shadow">
          <div className="mb-2 text-4xl">📝</div>
          <p>Нет привычек. Добавьте первую, чтобы начать отслеживать прогресс.</p>
        </div>
      ) : (
        <ul className="space-y-3">
          {habits.map((habit) => {
            const isDone = habit.completedDates.includes(today)
            return (
              <li
                key={habit.id}
                className={`flex items-center gap-4 rounded-lg border-l-4 bg-white p-4 shadow ${
                  isDone ? 'border-green-500 opacity-70' : 'border-indigo-500'
                }`}
              >
                <span className="text-2xl">{habit.icon}</span>

                <div className="flex-1">
                  <h3 className={`font-medium ${isDone ? 'text-slate-400 line-through' : ''}`}>
                    {habit.title}
                  </h3>
                  <p className="text-sm text-slate-500">
                    Выполнено дней: {habit.completedDates.length}
                  </p>
                </div>

                <button
                  onClick={() => toggleToday(habit.id)}
                  aria-pressed={isDone}
                  aria-label={isDone ? 'Отметить как невыполненную' : 'Отметить как выполненную'}
                  className={`size-11 rounded-full border text-lg ${
                    isDone
                      ? 'border-green-500 bg-green-500 text-white'
                      : 'border-slate-300 bg-white'
                  }`}
                >
                  {isDone ? '✓' : '○'}
                </button>

                <button
                  onClick={() => removeHabit(habit.id)}
                  aria-label={`Удалить привычку ${habit.title}`}
                  className="size-11 rounded-md text-lg hover:bg-red-50"
                >
                  🗑️
                </button>
              </li>
            )
          })}
        </ul>
      )}
    </div>
  )
}
```

> Классы `size-11` задают квадрат 44×44px — удобный размер цели нажатия на сенсорных экранах.

9. **Кнопка установки приложения.** Браузер сообщает о готовности установки событием `beforeinstallprompt`:

```tsx
// src/components/InstallButton.tsx
import { useEffect, useState } from 'react'

interface BeforeInstallPromptEvent extends Event {
  prompt: () => Promise<void>
  userChoice: Promise<{ outcome: 'accepted' | 'dismissed' }>
}

export function InstallButton() {
  const [deferredPrompt, setDeferredPrompt] =
    useState<BeforeInstallPromptEvent | null>(null)

  useEffect(() => {
    const handler = (event: Event) => {
      event.preventDefault()
      setDeferredPrompt(event as BeforeInstallPromptEvent)
    }

    window.addEventListener('beforeinstallprompt', handler)
    return () => window.removeEventListener('beforeinstallprompt', handler)
  }, [])

  if (!deferredPrompt) return null

  const handleInstall = async () => {
    await deferredPrompt.prompt()
    await deferredPrompt.userChoice
    setDeferredPrompt(null)
  }

  return (
    <button
      onClick={handleInstall}
      className="rounded-lg border border-indigo-600 px-4 py-2 text-indigo-600"
    >
      Установить приложение
    </button>
  )
}
```

10. **Проверка PWA.** Service worker работает только в собранном приложении:

```bash
npm run build
npm run preview
```

Откройте `http://localhost:4173` и проверьте в DevTools:

*   **Application → Manifest** — имя, короткое имя, цвета и иконки 192/512 видны без ошибок;
*   **Application → Service Workers** — статус `activated and is running`;
*   **Application → Cache Storage** — появились кэши статики (и `api-cache` при запросах);
*   поставьте галочку **Offline** на вкладке Service Workers и перезагрузите страницу — приложение должно открыться и показать сохранённые привычки;
*   в адресной строке Chrome появится значок установки — приложение можно добавить на устройство.

> Если после сборки изменения не видны, очистите кэш: DevTools → Application → Storage → Clear site data, затем перезагрузите страницу.

## **Инструкция по сдаче работы:**

1. Создать репозиторий на Gogs
2. Клонировать репозиторий локально
3. Создать React-проект в папке репозитория:
   ```bash
   npm create vite@latest . -- --template react-ts
   npm install
   ```
4. Установить `vite-plugin-pwa` и настроить `VitePWA` в `vite.config.ts`
5. Подготовить иконки 192×192 и 512×512 в папке `public/`
6. Реализовать приложение согласно варианту с сохранением данных локально
7. Сделать коммиты с понятными сообщениями
8. Добавить скриншоты работы (интерфейс, офлайн-режим, DevTools → Application) в папку `assets/images`
9. Оформить README.md
10. Запушить изменения в Gogs
11. Предоставить ссылку на репозиторий преподавателю
