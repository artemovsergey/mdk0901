# Практическая работа 21. Сервисный слой и Context

### **Тема:** Разделение UI и данных. Сервисные модули и Context-провайдеры

### **Цель:**
Научиться разделять интерфейс и логику работы с данными, выносить HTTP-запросы в отдельный сервисный слой и передавать общие данные через React Context. Освоить типизацию сервисных функций, настройку единого экземпляра Axios с базовым URL и интерцепторами, а также создание провайдера и хука доступа к контексту.

### **Теоретическая часть:**

**Зачем нужен сервисный слой.** Если запросы к серверу разбросаны по компонентам, код дублируется, сложно менять адреса API и обрабатывать ошибки единообразно. Сервисный слой — это набор модулей, которые отвечают только за взаимодействие с внешним миром. Компонент не знает, как именно устроен запрос: он вызывает функцию и получает типизированный результат.

**Принципы сервисного слоя:**
- **Разделение ответственности** — компонент отвечает за разметку и состояние экрана, сервис — за данные.
- **Переиспользование** — одну и ту же функцию запроса используют разные экраны.
- **Единая обработка ошибок** — логика обработки статусов собрана в одном месте.
- **Типизация** — на границе приложения данные приводятся к описанным типам.

**Структура каталогов:**
- `src/api/http.ts` — настроенный экземпляр Axios (базовый URL, заголовки, интерцепторы);
- `src/api/users.ts`, `src/api/products.ts` — функции-сервисы по предметным областям;
- `src/context/` — контексты и провайдеры;
- `src/types.ts` — общие типы.

**Экземпляр Axios с базовым URL:**
```ts
import axios from 'axios';

export const http = axios.create({
  baseURL: import.meta.env.VITE_API_URL ?? '/api',
  timeout: 10_000,
  headers: { 'Content-Type': 'application/json' },
});
```
Экземпляр создаётся один раз и переиспользуется во всех сервисах.

**Интерцепторы** — перехватчики, которые выполняются до отправки запроса или после получения ответа. В запрос обычно добавляют токен авторизации, в ответе — приводят сообщение об ошибке к единому виду.

**Что такое Context.** Контекст позволяет передавать данные через дерево компонентов, не прокидывая props на каждом уровне. Он состоит из трёх частей:
1. `createContext` — создаёт объект контекста со значением по умолчанию `null`;
2. компонент-провайдер `<Context.Provider value={...}>` — предоставляет значение потомкам;
3. хук доступа `useContext(Context)` — читает значение в любом компоненте внутри провайдера.

**Типизация контекста и защита от ошибок.** Значение по умолчанию делают `null`, а хук доступа выбрасывает ошибку, если провайдер забыли подключить. Это не даёт использовать контекст вне провайдера и получать непонятные ошибки.

```tsx
const AuthContext = createContext<AuthContextValue | null>(null);

export function useAuth(): AuthContextValue {
  const context = useContext(AuthContext);
  if (!context) {
    throw new Error('useAuth должен использоваться внутри AuthProvider');
  }
  return context;
}
```

**Провайдер и состояние.** Провайдер хранит состояние (`useState`) и методы его изменения, а через `value` передаёт их потомкам. Значение провайдера оборачивают в `useMemo`, чтобы не пересоздавать объект на каждый рендер.

**Axios или fetch.** `fetch` встроен в браузер и не требует зависимостей. Axios удобнее за счёт базового URL, интерцепторов и автоматического разбора JSON. В этой работе используется Axios; для небольших проектов допустим и `fetch`.

### **Ход работы:**

1. Создать новый React-проект (Vite + TypeScript) и установить `axios`.

3. **src/api/http.ts (единый экземпляр Axios):**
```tsx
import axios from 'axios';
import type { AxiosError, InternalAxiosRequestConfig } from 'axios';

export const http = axios.create({
  baseURL: import.meta.env.VITE_API_URL ?? 'https://jsonplaceholder.typicode.com',
  timeout: 10_000,
  headers: { 'Content-Type': 'application/json' },
});

// Добавляем токен ко всем исходящим запросам
http.interceptors.request.use((config: InternalAxiosRequestConfig) => {
  const token = localStorage.getItem('auth_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// Приводим ошибки к единому тексту на русском
http.interceptors.response.use(
  (response) => response,
  (error: AxiosError<{ message?: string }>) => {
    let message = 'Произошла ошибка при запросе к серверу';

    if (error.response) {
      switch (error.response.status) {
        case 400:
          message = 'Неверный запрос';
          break;
        case 401:
          message = 'Не авторизован';
          break;
        case 403:
          message = 'Доступ запрещён';
          break;
        case 404:
          message = 'Ресурс не найден';
          break;
        case 500:
          message = 'Внутренняя ошибка сервера';
          break;
        default:
          message = `Ошибка ${error.response.status}`;
      }
    } else if (error.request) {
      message = 'Нет соединения с сервером';
    }

    return Promise.reject(new Error(message));
  },
);
```

import { http } from './http';
import type { User } from '../types';

/** Загружает список пользователей. */
export async function fetchUsers(): Promise<User[]> {
  const { data } = await http.get<User[]>('/users');
  return data;
}

/** Загружает одного пользователя по идентификатору. */
export async function fetchUserById(id: number): Promise<User> {
  const { data } = await http.get<User>(`/users/${id}`);
  return data;
}

/** Имитация входа: проверяем данные и возвращаем сессию. */
export async function login(email: string, password: string) {
  const { data } = await http.get<User[]>('/users', { params: { email } });
  const user = data[0];

  if (!user || password.length < 4) {
    throw new Error('Неверный email или пароль');
  }

  return {
    token: `demo-token-${user.id}`,
    user: { id: user.id, name: user.name, email: user.email },
  };
}

5. **src/context/AuthContext.tsx (провайдер авторизации + хук доступа):**
```tsx
import { createContext, useCallback, useContext, useMemo, useState } from 'react';
import type { ReactNode } from 'react';
import { login as loginRequest } from '../api/users';
import type { AuthSession } from '../types';

interface AuthContextValue {
  user: AuthSession['user'] | null;
  isAuthenticated: boolean;
  login: (email: string, password: string) => Promise<void>;
  logout: () => void;
}

const STORAGE_KEY = 'auth_session';

const AuthContext = createContext<AuthContextValue | null>(null);

function readStoredSession(): AuthSession | null {
  try {
    const raw = localStorage.getItem(STORAGE_KEY);
    return raw ? (JSON.parse(raw) as AuthSession) : null;
  } catch {
    return null;
  }
}

export function AuthProvider({ children }: { children: ReactNode }) {
  const [session, setSession] = useState<AuthSession | null>(readStoredSession);

  const login = useCallback(async (email: string, password: string) => {
    const newSession = await loginRequest(email, password);
    localStorage.setItem('auth_token', newSession.token);
    localStorage.setItem(STORAGE_KEY, JSON.stringify(newSession));
    setSession(newSession);
  }, []);

  const logout = useCallback(() => {
    localStorage.removeItem('auth_token');
    localStorage.removeItem(STORAGE_KEY);
    setSession(null);
  }, []);

  const value = useMemo<AuthContextValue>(
    () => ({
      user: session?.user ?? null,
      isAuthenticated: session !== null,
      login,
      logout,
    }),
    [session, login, logout],
  );

  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>;
}

/** Хук доступа к контексту авторизации. */
export function useAuth(): AuthContextValue {
  const context = useContext(AuthContext);
  if (!context) {
    throw new Error('useAuth должен использоваться внутри AuthProvider');
  }
  return context;
}
```

8. **src/components/LoginForm.tsx:**
```tsx
import { useState } from 'react';
import type { FormEvent } from 'react';
import { useAuth } from '../context/AuthContext';

export function LoginForm() {
  const { login } = useAuth();
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [error, setError] = useState<string | null>(null);
  const [loading, setLoading] = useState(false);

  async function handleSubmit(event: FormEvent<HTMLFormElement>) {
    event.preventDefault();
    setError(null);
    setLoading(true);

    try {
      await login(email, password);
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Не удалось войти');
    } finally {
      setLoading(false);
    }
  }

  return (
    <form className="login-form" onSubmit={handleSubmit}>
      <h2>Вход</h2>

      <label>
        <span>Email</span>
        <input
          type="email"
          value={email}
          onChange={(event) => setEmail(event.target.value)}
          required
        />
      </label>

      <label>
        <span>Пароль</span>
        <input
          type="password"
          value={password}
          onChange={(event) => setPassword(event.target.value)}
          required
        />
      </label>

      {error && (
        <p className="error" role="alert">
          {error}
        </p>
      )}

      <button type="submit" disabled={loading}>
        {loading ? 'Отправка…' : 'Войти'}
      </button>
    </form>
  );
}
```

9. **src/components/UserList.tsx (данные из сервиса):**
```tsx
import { useEffect, useState } from 'react';
import { fetchUsers } from '../api/users';
import type { User } from '../types';

export function UserList() {
  const [users, setUsers] = useState<User[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    let cancelled = false;

    async function load() {
      try {
        const data = await fetchUsers();
        if (!cancelled) {
          setUsers(data);
        }
      } catch (err) {
        if (!cancelled) {
          setError(err instanceof Error ? err.message : 'Ошибка загрузки');
        }
      } finally {
        if (!cancelled) {
          setLoading(false);
        }
      }
    }

    void load();

    return () => {
      cancelled = true;
    };
  }, []);

  if (loading) {
    return <p className="state">Загрузка пользователей…</p>;
  }

  if (error) {
    return (
      <p className="state state-error" role="alert">
        {error}
      </p>
    );
  }

  return (
    <ul className="user-grid">
      {users.map((user) => (
        <li key={user.id} className="user-card">
          <h3>{user.name}</h3>
          <p>{user.email}</p>
          <p className="company">{user.company.name}</p>
        </li>
      ))}
    </ul>
  );
}
```
