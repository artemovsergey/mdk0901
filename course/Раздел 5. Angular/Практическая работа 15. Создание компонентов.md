# Практическая работа 15. Создание компонентов в React

### **Тема:** Компоненты React — основные строительные блоки приложения

### **Цель:**
Научиться создавать функциональные компоненты в React, понимать их структуру и взаимодействие между ними. Освоить JSX, передачу данных через props, типизацию props с помощью TypeScript и композицию компонентов.

### **Теоретическая часть:**

**Компонент** в React — это функция, которая возвращает JSX-разметку. Компонент включает:
- **Функцию** — содержит логику и вычисления
- **JSX-разметку** — то, что функция возвращает
- **Props** — входные данные компонента
- **Стили** — CSS-файл, подключённый к компоненту

**Минимальный компонент:**
```tsx
function MyComponent() {
  return <div>Мой компонент</div>;
}
```

**Правила компонентов:**
- Имя компонента начинается с **заглавной буквы** — так React отличает компоненты от обычных HTML-тегов
- Компонент возвращает **один корневой элемент** (или Fragment `<>...</>`, если элементов несколько)
- Файлы компонентов называют с заглавной буквы: `Button.tsx`, `UserCard.tsx`
- Каталог `src/components/` — договорённость для хранения компонентов приложения

**Props и их типизация:**
```tsx
interface GreetingProps {
  name: string;        // обязательное свойство
  city?: string;       // необязательное свойство (знак вопроса)
}

function Greeting({ name, city }: GreetingProps) {
  return <p>Привет, {name}! Город: {city ?? 'не указан'}</p>;
}
```

**Экспорт и импорт компонентов:**
```tsx
// components/Button.tsx — именованный экспорт
export function Button() {
  return <button>Кнопка</button>;
}

// App.tsx — импорт
import { Button } from './components/Button';
```

**Композиция:** компоненты вкладываются друг в друга; props могут быть не только данными, но и функциями (обработчики событий) и JSX-разметкой.

### **Ход работы:**

1. Создать новый React-проект (Vite + TypeScript)
2. Изучить структуру проекта
3. Создать компоненты согласно варианту задания в папке `src/components/`
4. Настроить передачу данных через props и взаимодействие между компонентами
5. Добавить стилизацию (CSS-файлы)
6. Проверить работу в браузере (`npm run dev`)
7. Оформить README.md с описанием работы

### **Практический пример:**

**Создание компонента кнопки:**

1. **Создание и запуск проекта:**
```bash
npm create vite@latest button-demo -- --template react-ts
cd button-demo
npm install
npm run dev
```

2. **src/components/Button.tsx:**
```tsx
import './Button.css';

type ButtonVariant = 'primary' | 'secondary' | 'danger';

interface ButtonProps {
  text: string;
  variant?: ButtonVariant;
  disabled?: boolean;
  onClick: () => void;
}

export function Button({
  text,
  variant = 'primary',
  disabled = false,
  onClick,
}: ButtonProps) {
  return (
    <button
      className={`btn btn-${variant}`}
      disabled={disabled}
      onClick={onClick}
    >
      {text}
    </button>
  );
}
```

3. **src/components/Button.css:**
```css
.btn {
  padding: 10px 20px;
  border: none;
  border-radius: 5px;
  cursor: pointer;
  font-size: 16px;
  transition: all 0.3s ease;
}

.btn-primary {
  background-color: #007bff;
  color: white;
}

.btn-secondary {
  background-color: #6c757d;
  color: white;
}

.btn-danger {
  background-color: #dc3545;
  color: white;
}

.btn:disabled {
  opacity: 0.6;
  cursor: not-allowed;
}

.btn:hover:not(:disabled) {
  opacity: 0.8;
  transform: translateY(-2px);
}
```

4. **Использование в App.tsx:**
```tsx
import './App.css';
import { Button } from './components/Button';

function App() {
  const handleSave = () => {
    alert('Данные сохранены!');
  };

  return (
    <div className="app">
      <h1>Пример с компонентом кнопки</h1>
      <Button text="Сохранить" variant="primary" onClick={handleSave} />
      <Button text="Удалить" variant="danger" onClick={() => alert('Удалено!')} />
    </div>
  );
}

export default App;
```

#### src/components/UserCard.tsx
```tsx
import './UserCard.css';

export interface User {
  id: number;
  firstName: string;
  lastName: string;
  email: string;
  avatarUrl: string;
}

interface UserCardProps {
  user: User;
  onMessageClick: (id: number) => void;
}

export function UserCard({ user, onMessageClick }: UserCardProps) {
  const fullName = `${user.firstName} ${user.lastName}`;

  return (
    <div className="user-card">
      <div className="user-avatar">
        <img src={user.avatarUrl} alt={fullName} />
      </div>

      <div className="user-info">
        <h3 className="user-name">{fullName}</h3>
        <p className="user-email">{user.email}</p>
      </div>

      <button className="message-btn" onClick={() => onMessageClick(user.id)}>
        Написать сообщение
      </button>
    </div>
  );
}
```

  };

    <div className="container">
