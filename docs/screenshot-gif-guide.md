# Руководство по снятию скриншотов и GIF для практических работ

## Инструменты
- Скриншоты: Win+Shift+S (Snipping Tool) или ShareX
- GIF: ScreenToGif (рекомендуется), LICEcap
- Сохранять в `course/Раздел 5. React/assets/practical-XX/images/`

## Правила именования
- `step-01-create-project.png`, `step-02-result.png`
- GIF: `demo-form-submit.gif`, `demo-navigation.gif`
- Макс. ширина 1280 px, формат PNG/JPG для фото, GIF для анимаций

## Что снимать
1. Создание проекта (команда + результат)
2. Ключевой шаг реализации (код + результат)
3. Финальный результат в браузере
4. Ошибки и их исправление (по возможности)

## Как вставлять в .md
```markdown
![Описание шага](assets/practical-15/images/step-01-create-project.png)
```

## GIF-демонстрации
- Длительность 5-15 сек, без звука
- Показывать одно действие: ввод данных → отправка → результат
- Размер файла < 5 МБ

## Чек-лист перед сдачей
- [ ] Все шаги имеют скриншот или GIF
- [ ] Изображения открываются в markdown-превью
- [ ] Имена файлов на латинице, без пробелов
- [ ] Вариант задания выполнен полностью
```
