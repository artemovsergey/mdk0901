# Миграция курса МДК 09.01 с Angular на React — рабочий документ

> Референс для авторов контента. Курс — только markdown-материалы на русском языке.
> Все примеры кода должны соответствовать актуальным версиям библиотек.

## Стек (утверждён)

| Область | Технология |
|---------|------------|
| Сборка | Vite (шаблон `react-ts`) |
| UI-библиотека | React 19 |
| Язык | TypeScript |
| Маршрутизация | React Router 7 |
| Серверное состояние | TanStack Query v5 |
| HTTP-клиент | Axios (+ fetch) |
| Формы и валидация | react-hook-form + zod |
| Клиентское состояние | Zustand |
| Тесты | Vitest + React Testing Library |
| PWA | vite-plugin-pwa |
| UI-компоненты | shadcn/ui + Tailwind CSS |
| WebSocket | @microsoft/signalr |

## Правила оформления материалов

- Язык — русский; термины на английском уместны (props, state, hook).
- Формат лекций сохранять: Цель → Аудитория → План → Детальное рассмотрение → Резюме → Контрольные вопросы (~10).
- Формат практик сохранять: Тема → Цель → Теоретическая часть → Ход работы → Практический пример → 15 вариантов → Критерии 5/4/3/2 → Контрольные вопросы (10–15) → Файловая структура → Пример README.md → Инструкция по сдаче (Gogs).
- Команды: `npm install`, `npm run dev` (http://localhost:5173), `npm run build`, `npm run preview` (http://localhost:4173), `npm test` (Vitest).
- Не оставлять упоминаний Angular: NgModule, декораторы, `@Component`, `*ngFor`, RxJS, Jasmine/Karma, команд `ng`, angular.dev и пр.
- Имена файлов — каноничны; нумерация внутри заголовков должна совпадать с именем файла.
- Ссылки в лекциях: react.dev, vite.dev, reactrouter.com, tanstack.com/query, ui.shadcn.com, vitest.dev, testing-library.com.
